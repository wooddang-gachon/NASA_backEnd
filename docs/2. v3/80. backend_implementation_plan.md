# TAMMY v3 백엔드 구현 계획서 (Backend Implementation Plan)

본 문서는 TAMMY v3 시스템 아키텍처 및 기능 명세서에 따라 백엔드(Node.js / Express or Fastify) 서비스를 구축하기 위한 단계별 구현 로드맵입니다.

---

## 📅 단계별 백엔드 구현 로드맵

### Phase 1: 기반 인프라 & DB 스키마 구축
1. **Prisma ORM & PostgreSQL 데이터베이스 마이그레이션**
   - `User`, `QuickLog`, `FoodLog`, `PlanetTravel`, `Report`, `ChatMessage` 엔티티 마이그레이션 적용
2. **JWT 회원 인증 & 계정 관리 API 구현**
   - 회원가입 (`POST /api/v3/auth/register`), 로그인 (`POST /api/v3/auth/login`)
   - JWT Access/Refresh Token 인증 미들웨어 및 자동 갱신 (`POST /api/v3/auth/refresh`)
   - 회원 탈퇴 & 데이터 비식별화 (`POST /api/v3/auth/withdraw`)

---

### Phase 2: 1-Tap 퀵버튼 & 연료(Fuel) 보상 엔진
1. **1-Tap 데일리 기록 API 구현 (`POST /api/v3/quick-log`)**
   - 물 섭취, 감정 선택, 감정일기 작성, 운동 시간 단축 입력 처리
2. **연료(Fuel) 적립 알고리즘 구현**
   - 기록 작성 성공 시 사용자 `currentFuel` 포인트 자동 계산 및 DB 업데이트 (+10 Fuel)

---

### Phase 3: 하이브리드 Food Vision 파이프라인
1. **BE 이미지 리사이징 & 압축 모듈 구축 (`sharp` 라이브러리)**
   - 업로드된 사진을 512x512 Low-Res 모드로 압축 처리
2. **BE 내장 경량 YOLO 모델 1차 검토 구축 (`onnxruntime-node`)**
   - 압축 이미지에 대해 1차 음식 신뢰도(Confidence) 검사 수행
   - 신뢰도 충족 시 즉시 식단/영양 결과 반환 (외부 API 호출 0원 처리)
3. **AI-server Vision LLM Fallback 연동 (`POST /api/v3/food-vision/scan`)**
   - YOLO 미식별/불분명 시 백엔드가 AI-server로 멀티모달 비전 스캔 요청
4. **수동 확정 식단 저장 API 구현 (`POST /api/v3/food-log/confirm`)**

---

### Phase 4: AI 타미 심리 공감 대화 파이프라인
1. **메시지 DB 즉시 선저장 처리 (`POST /api/v3/chat/message`)**
   - 사용자 메시지 수신 즉시 `ChatMessage` 테이블에 선저장
2. **AI-server 대화 연동 & 종합 가공 수령**
   - AI-server로 메시지 전달 -> 심리 공감 응답 및 감정/웰니스 정보 종합 가공 결과 수령 -> DB 저장 후 FE로 최종 반환
3. **대화 삭제 & Undo 복구 API 구현 (`DELETE /api/v3/chat/messages/{id}`, `POST /undo`)**

---

### Phase 5: 별여행 비동기 리포트 & 푸시 알림 파이프라인
1. **별여행 탐사 출발 API 구현 (`POST /api/v3/planet-travel/start`)**
   - 연료(Fuel) 차감 및 탐사 상태 `IN_PROGRESS` 저장
2. **Task Queue & Worker 구축 (BullMQ / Redis)**
   - 비동기 백그라운드 리포트 생성 작업을 Task Queue에 Push
   - Worker가 해당 행성(식사, 수분, 감정, 생활습관, 회고) 테마 데이터 수집 후 AI-server에 맞춤 리포트 요청
3. **푸시 알림 Dispatcher 연동 (FCM / APNs)**
   - 리포트 저장 완료 시 사용자 디바이스로 Push Notification 알림 발송
4. **리포트 상세 조회 API 구현 (`GET /api/v3/reports/{reportId}`)**

---

### Phase 6: 건강 인사이트 대시보드 & 종합 테스트
1. **상시 웰니스 대시보드 통계 API 구현 (`GET /api/v3/dashboard/summary`)**
   - 칼로리 추이, 3대 영양소 밸런스, 미션 수행 현황 누적 데이터 집계
2. **통합 시퀀스 테스트 & 부하 검증 (Load Testing)**
