# TAMMY v3 서비스 기획서 (Product Requirement Document)

## 1. 프로젝트 개요 (Overview)

- **서비스명**: TAMMY v3 (AI 타미 메이트 기반 심리 공감 & 웰니스 별여행)
- **기획 배경**: 기존 웰니스 앱의 과도한 수동 입력 피로감과 심리 케어/식단 트래킹 서비스의 분리 문제를 해결하고, 지치지 않는 지속 가능한 웰니스 경험 제공
- **핵심 비전**: **"마음 케어와 건강 기록이 즐거운 별여행이 되는 웰니스 메이트"**

---

## 2. 타겟 사용자 & 핵심 페인포인트 (Target & Pain Points)

- **주요 타겟**: 바쁜 일상 속 건강 관리와 마음 정리가 동시에 필요한 2030 세대
- **핵심 페인포인트**:
  - 기존 칼로리 계산 앱의 복잡하고 번거로운 검색/입력 절차 (도중 포기율 높음)
  - 단순 수치 기록에 그쳐 지루하고 지속적인 동기부여 요소 부재
  - 심리적 스트레스와 식습관/생활습관이 긴밀히 연결되어 있으나 별개로 관리되는 문제

---

## 3. 핵심 UX 컨셉 & 세계관 (Concept & Gamification)

### 3.1 1-Tap 퀵버튼 (Zero-Friction UX)
기록의 번거로움을 극단적으로 줄이는 원터치 인터페이스
- **기능 실행**: 사진 촬영 (Food Vision 스캔), 리포트 생성 (AI 인사이트)
- **데일리 기록**: 물 기록, 감정 기록, 감정일기, 운동 기록

### 3.2 타미 별여행 세계관 (Planet Exploration System)
미션 수행과 데일리 기록을 통해 **'연료(Fuel)'**를 충전하고, 5대 행성으로 별여행을 떠나 탐사 완료 후 **맞춤 AI 리포트**를 수령하는 게이미피케이션
- **식사별**: 식단 사진 및 영양 밸런스 탐사
- **수분별**: 일일 수분 섭취 패턴 탐사
- **감정별**: 감정 상태 및 감정일기 심리 탐사
- **생활습관별**: 운동 및 데일리 웰니스 습관 탐사
- **회고별 (자동 실행)**: 주간/월간 특정 기간마다 자동 실행되는 종합 회고 탐사

---

## 4. 서비스 핵심 기능 구조 (Core Function Matrix)

1. **AI 타미 심리 공감 대화**:
   - 메시지 수령 즉시 BE에서 DB 선저장 -> AI-server에서 심리 공감 및 관련 웰니스 정보 종합 가공 -> BE 전달 및 대화 응답 출력

2. **하이브리드 Food Vision AI 스캔**:
   - BE 이미지 압축(512x512) -> 자체 경량 YOLO 1차 검토 (명확 시 0원 비용 즉시 완료) -> 미식별/불분명 시 외부 Vision LLM Fallback 요청 -> 수동 검수 편집 카드 UI 제공

3. **비동기 맞춤 리포트 & 푸시 알림**:
   - 별여행 탐사 복귀 및 요청 시 백그라운드 Worker에서 LLM 기반 맞춤 리포트 가공 -> Push Notification 완료 알림 발송 -> 딥링크 상세 조회

---

## 5. 비용 & 아키텍처 최적화 전략 (Optimization Strategy)
- **Vision API 비용 최소화**: Low-Res 512px 압축, 묶음(Batch) 프롬프트 호출, YOLO 1차 Filtering
- **Human-in-the-loop UX**: AI는 짧은 음식 후보 태그만 반환하고 확정/양 조절은 사용자가 직접 선택하여 Output 토큰 최소화

---

## 6. 서비스 확장 로드맵 (Roadmap)
- **1단계 (현재 MVP)**: RDBMS Context Injection, 1-Tap 퀵버튼, 5대 별여행 탐사, YOLO + Vision LLM 하이브리드 파이프라인
- **2단계 (서비스 고도화)**: Pgvector 기반 RAG 장기 기억 파이프라인 도입, 자체 서버 음식 분류 AI 모델 microservice 전면 내재화 (API 비용 0원화)
