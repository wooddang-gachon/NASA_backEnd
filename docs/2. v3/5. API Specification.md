# TAMMY v3 API 명세서 (API Specification)

본 문서는 TAMMY v3의 주요 기능(1-Tap 퀵버튼, Food Vision, 별여행 게이미피케이션, AI 심리 공감 채팅 등)을 수행하기 위한 백엔드 RESTful API 사양서입니다.

---

## 1. 1-Tap 퀵버튼 기록 API

### `POST /api/v3/quick-log`
- **설명**: 물 섭취, 감정, 감정일기, 1-Tap 운동 단순 기록 등의 데일리 웰니스 항목을 원터치 기록하고 연료(Fuel)를 적립합니다.

#### Request Body
```json
{
  "category": "WATER | EMOTION | JOURNAL | EXERCISE",
  "amount": 250,
  "emotionType": "HAPPY",
  "journalContent": "오늘 하루도 알차게 보냈다.",
  "durationMinutes": 30
}
```

#### Response (200 OK)
```json
{
  "success": true,
  "message": "기록이 완료되었습니다.",
  "data": {
    "logId": "log_12345",
    "category": "EXERCISE",
    "earnedFuel": 10,
    "totalFuel": 150
  }
}
```

## 2. Food Vision 스캔 & 기록 확정 API

### 2.1 `POST /api/v3/food-vision/scan`
- **설명**: 식단 사진을 업로드합니다. 백엔드에서 이미지 압축(512x512) 및 자체 경량 YOLO 1차 검토 후, 미식별/불분명 시 AI-server(Vision LLM)로 Fallback 분석을 수행하여 결과를 반환합니다.
- **Content-Type**: `multipart/form-data`

#### Request Parameters
- `image`: File (Binary Image File)

#### Response (200 OK)
```json
{
  "success": true,
  "data": {
    "scanEngine": "YOLO | VISION_LLM",
    "isFallbackUsed": false,
    "detectedFoods": [
      {
        "foodName": "제육볶음",
        "estimatedGram": 200,
        "calories": 350,
        "carbs": 12.5,
        "protein": 28.0,
        "fat": 18.2
      }
    ]
  }
}
```

### 2.2 `POST /api/v3/food-log/confirm`
- **설명**: 수동 검수 편집 카드를 통해 사용자가 확정한 최종 식단 데이터를 DB에 저장합니다.

#### Request Body
```json
{
  "mealType": "LUNCH",
  "foods": [
    {
      "foodName": "제육볶음",
      "gram": 200,
      "calories": 350,
      "carbs": 12.5,
      "protein": 28.0,
      "fat": 18.2
    }
  ]
}
```

#### Response (200 OK)
```json
{
  "success": true,
  "message": "식단 기록이 확정되었습니다."
}
```

## 3. 별여행 게이미피케이션 & 리포트 API

### 3.1 `POST /api/v3/planet-travel/start`
- **설명**: 연료(Fuel)를 소진하여 선택한 행성(식사, 수분, 감정, 생활습관, 회고)으로 별여행 탐사를 출발합니다. 백그라운드에서 비동기 리포트 생성이 요청됩니다.

#### Request Body
```json
{
  "planetType": "MEAL | WATER | EMOTION | LIFESTYLE | RETROSPECT",
  "fuelSpent": 50
}
```

#### Response (202 Accepted)
```json
{
  "success": true,
  "message": "별여행 탐사를 출발했습니다. 완료 시 리포트 알림이 전송됩니다.",
  "data": {
    "travelId": "travel_9876",
    "planetType": "MEAL",
    "remainingFuel": 100
  }
}
```

### 3.2 `GET /api/v3/reports/{reportId}`
- **설명**: 별여행 탐사 완료 후 발급된 맞춤 AI 인사이트 리포트 상세 내용을 조회합니다.

## 4. AI 타미 심리 공감 채팅 API

### `POST /api/v3/chat/message`
- **설명**: 사용자 메시지를 수신하여 즉시 DB에 저장하고, AI-server로 전달하여 심리 공감 및 관련 웰니스 정보가 종합 가공된 답변을 반환합니다.

#### Request Body
```json
{
  "messageText": "오늘 업무가 너무 많아서 힘들었어."
}
```

#### Response (200 OK)
```json
{
  "success": true,
  "data": {
    "messageId": "msg_777",
    "responseText": "오늘 정말 고생 많으셨어요!",
    "motionTag": "COMFORT_WARM",
    "createdAt": "2026-08-05T16:31:00Z"
  }
}
```
