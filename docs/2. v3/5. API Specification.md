# TAMMY v3 백엔드 & AI 연동 통합 API 명세서 (API Specification)

본 문서는 TAMMY v3 서비스 백엔드(Node.js / Express or Fastify)의 외부 RESTful API 및 **FE (클라이언트) ↔ BE (백엔드) ↔ AI-server (LLM & Vision Engine)** 간 3자 오케스트레이션 프로토콜 통합 명세서입니다.

---

## 1. 개요 및 FE ↔ BE ↔ AI 3자 파이프라인 규약

### 1.1 기본 접속 정보 및 인증 규약
- **BE API Base URL**: `http://localhost:3000/api/v3`
- **AI Server Base URL**: `http://ai-server:8000/v1` (FastAPI / LLM Engine 연동)
- **인증(Authentication)**: JWT Bearer Token 헤더 (`Authorization: Bearer <AccessToken>`)

### 1.2 BE ↔ AI 연동 핵심 3대 흐름 (Architecture Flow)
1. **하이브리드 Food Vision 파이프라인**:
   - FE 사진 전송 ➔ BE에서 512x512 이미지 압축 ➔ BE 내장 YOLO 1차 검토 (명확 시 0원 처리) ➔ 미식별/불분명 시 AI-server (Vision LLM) 추가 스캔 ➔ FE 수동 검수 편집 카드 출력
2. **별여행 탐사 비동기 리포트 파이프라인**:
   - 사용자가 연료(Fuel) 소진하여 5대 행성 탐사 출발 ➔ Task Queue 비동기 전달 ➔ 백그라운드 Worker가 AI-server에 맞춤 리포트 요청 ➔ 리포트 DB 저장 & Push Notification 발송
3. **AI 심리 공감 대화 & DB 선저장 파이프라인**:
   - FE 메시지 전송 ➔ BE에서 DB에 메시지 즉시 저장 ➔ AI-server로 메시지 및 사용자 프로필 전달 ➔ AI-server 내부에서 공감 답변 및 관련 감정/웰니스 정보 종합 가공/정리 ➔ BE 수령 후 DB 저장 및 FE 반환

---

## 2. AI 서버 (tammy-agent) 연동 내부 프로토콜 스펙

### 2.1 [AI-001] 멀티모달 비전 스캔 Fallback API (`POST http://ai-server:8000/v1/vision/scan`)
BE의 1차 YOLO 검토에서 미식별/불분명으로 판정된 경우 호출되는 외부 Vision LLM API입니다.

- **BE ➔ AI 요청**:
  - `compressedImageUrl`: BE에서 512x512로 압축된 이미지 URL 또는 Base64
  - `mealType`: 식사 종류 (`BREAKFAST` | `LUNCH` | `DINNER` | `SNACK`)
- **AI ➔ BE 응답**:
  - `isIdentified`: 인식 여부 (boolean)
  - `detectedFoods`: 식별된 음식 및 3대 영양소/칼로리 추정 배열
    - `foodName`: 음식명
    - `estimatedGram`: 추정 중량 (g)
    - `calories`: 칼로리 (kcal)
    - `carbs`: 탄수화물 (g)
    - `protein`: 단백질 (g)
    - `fat`: 지방 (g)

### 2.2 [AI-002] 심리 공감 대화 & 종합 가공 API (`POST http://ai-server:8000/v1/chat/process`)
- **BE ➔ AI 요청**:
  - `userId`: 유저 ID
  - `userMessage`: 유저 대화 메시지
  - `userContext`: 최근 기분, 수분/운동 섭취 현황 정량 수치 (Context Injection)
- **AI ➔ BE 응답**:
  - `responseText`: 타미 심리 공감 응답 메시지
  - `motionTag`: 타미 반응 모션 애니메이션 태그 (`COMFORT_WARM` | `HAPPY_BOUNCE` 등)
  - `emotionSummary`: 대화에서 추출된 기분/감정 요약문

### 2.3 [AI-003] 5대 행성 맞춤 리포트 생성 API (`POST http://ai-server:8000/v1/reports/summarize`)
- **BE ➔ AI 요청 (통합 집계 페이로드)**:
  - `userId`: 유저 ID
  - `planetType`: 5대 행성 테마 (`MEAL` | `WATER` | `EMOTION` | `LIFESTYLE` | `RETROSPECT`)
  - `periodFrom`: 시작 일자 (`YYYY-MM-DD`)
  - `periodTo`: 종료 일자 (`YYYY-MM-DD`)
  - `historyData`: 해당 행성 주제에 대한 섭취, 운동, 수분, 감정 기록 데이터 집계
- **AI ➔ BE 응답**:
  - `reportTitle`: 리포트 제목
  - `summaryContent`: AI 진단 요약문
  - `recommendations`: 맞춤 가이드라인 추천 문장 배열

## 3. 외부 백엔드 RESTful API 상세 스펙

### 3.1 회원 인증 & 계정 관리 API (`/api/v3/auth`)

#### 3.1.1 `POST /api/v3/auth/register`
- **설명**: 이메일과 비밀번호 기반으로 신규 회원가입을 수행하고 초기 펫/우주선 상태를 생성한 뒤 JWT 토큰을 발급합니다.
- **Request Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!",
    "nickname": "우주탐험가",
    "gender": "MALE",
    "age": 25,
    "targetWeightKg": 68.5,
    "waterGoalMl": 2000,
    "calorieGoalKcal": 2200
  }
  ```
- **Response (201 Created)**:
  ```json
  {
    "user": {
      "id": 1,
      "email": "user@example.com",
      "nickname": "우주탐험가",
      "authProvider": "LOCAL"
    },
    "accessToken": "eyJhbGciOiJIUzI1Ni...",
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```

#### 3.1.2 `POST /api/v3/auth/login`
- **설명**: 등록된 이메일과 비밀번호로 로그인하여 JWT Access Token과 Refresh Token을 발급받습니다.
- **Request Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "user": {
      "id": 1,
      "email": "user@example.com",
      "nickname": "우주탐험가",
      "authProvider": "LOCAL"
    },
    "accessToken": "eyJhbGciOiJIUzI1Ni...",
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```

#### 3.1.3 `POST /api/v3/auth/social-login`
- **설명**: 구글(Google), 카카오(Kakao), 애플(Apple) SDK에서 발급받은 OAuth 토큰(`access_token` 또는 `id_token`)을 검증하고, 미가입 시 자동 회원가입 처리 후 JWT 토큰을 발급합니다.
- **Request Body**:
  ```json
  {
    "provider": "GOOGLE | KAKAO | APPLE",
    "token": "ya29.a0AfH6SM... (또는 카카오/애플 발급 토큰)",
    "nickname": "우주탐험가"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "user": {
      "id": 2,
      "email": "user@gmail.com",
      "nickname": "우주탐험가",
      "authProvider": "GOOGLE"
    },
    "accessToken": "eyJhbGciOiJIUzI1Ni...",
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```

#### 3.1.4 `POST /api/v3/auth/refresh`
- **설명**: 만료된 Access Token을 재발급하기 위해 유효한 Refresh Token을 전달합니다. (RTR 정책 적용)
- **Request Body**:
  ```json
  {
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "accessToken": "eyJhbGciOiJIUzI1Ni...",
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```

#### 3.1.5 `POST /api/v3/auth/withdraw` (또는 `DELETE /api/v3/auth/withdraw`)
- **설명**: 회원 탈퇴를 처리하고 유저 상태를 `WITHDRAWN`으로 변경 및 Refresh Token을 삭제합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Request Body** (선택):
  ```json
  {
    "reason": "서비스 이용 빈도 감소"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "회원 탈퇴 처리가 완료되었습니다."
  }
  ```

### 3.2 1-Tap 퀵버튼 데일리 기록 API (`/api/v3/quick-log`)
- **`POST /api/v3/quick-log`**
  - **설명**: 물 섭취, 감정, 감정일기, 1-Tap 운동 단순 기록 등의 데일리 웰니스 항목을 원터치 기록하고 연료(Fuel)를 적립합니다.
  - **Request Body**:
    ```json
    {
      "category": "WATER | EMOTION | JOURNAL | EXERCISE",
      "amount": 250,
      "emotionType": "HAPPY",
      "journalContent": "오늘 하루도 알차게 보냈다.",
      "exerciseName": "러닝",
      "durationMinutes": 30
    }
    ```
  - **Response (200 OK)**:
    ```json
    {
      "success": true,
      "message": "기록이 완료되었습니다.",
      "data": {
        "logId": "log_12345",
        "category": "EXERCISE",
        "earnedFuel": 10,
        "totalFuel": 150
      }
    }
    ```

### 3.3 Food Vision 스캔 & 기록 확정 API (`/api/v3/food-vision`, `/api/v3/food-log`)
- **`POST /api/v3/food-vision/scan`** (Content-Type: `multipart/form-data`)
  - **설명**: 식단 사진 업로드 후 BE에서 512x512 압축 및 YOLO 1차 검토 진행. 미식별 시 AI-server Fallback 분석 수행 후 결과 반환.
  - **Request Parameters**: `image` (Binary Image File)
  - **Response (200 OK)**:
    ```json
    {
      "success": true,
      "data": {
        "scanEngine": "YOLO | VISION_LLM",
        "isFallbackUsed": false,
        "detectedFoods": [
          {
            "foodName": "제육볶음",
            "estimatedGram": 200,
            "calories": 350,
            "carbs": 12.5,
            "protein": 28.0,
            "fat": 18.2
          }
        ]
      }
    }
    ```
- **`POST /api/v3/food-log/confirm`**
  - **설명**: 수동 검수 편집 카드를 통해 사용자가 최종 확정한 식단 영양 데이터를 DB에 저장합니다.
  - **Request Body**:
    ```json
    {
      "mealType": "LUNCH",
      "foods": [
        {
          "foodName": "제육볶음",
          "gram": 200,
          "calories": 350,
          "carbs": 12.5,
          "protein": 28.0,
          "fat": 18.2
        }
      ]
    }
    ```
  - **Response (200 OK)**:
    ```json
    {
      "success": true,
      "message": "식단 기록이 확정되었습니다."
    }
    ```

### 3.4 별여행 게이미피케이션 & 리포트 API (`/api/v3/planet-travel`, `/api/v3/reports`)
- **`POST /api/v3/planet-travel/start`**
  - **설명**: 연료(Fuel)를 소진하여 선택한 행성 탐사를 출발하고, 비동기 리포트 생성을 요청합니다.
  - **Request Body**:
    ```json
    {
      "planetType": "MEAL | WATER | EMOTION | LIFESTYLE | RETROSPECT",
      "fuelSpent": 50
    }
    ```
  - **Response (202 Accepted)**:
    ```json
    {
      "success": true,
      "message": "별여행 탐사를 출발했습니다. 완료 시 리포트 알림이 전송됩니다.",
      "data": {
        "travelId": "travel_9876",
        "planetType": "MEAL",
        "remainingFuel": 100
      }
    }
    ```
- **`GET /api/v3/reports/{reportId}`**
  - **설명**: 탐사 완료 후 발급된 맞춤 AI 인사이트 리포트 상세 내용을 조회합니다.

### 3.5 AI 타미 심리 공감 채팅 API (`/api/v3/chat`)
- **`POST /api/v3/chat/message`**
  - **설명**: 사용자 메시지를 수신하여 DB 저장 후 AI-server로 전달, 심리 공감 답변 및 관련 태그를 반환합니다.
  - **Request Body**:
    ```json
    {
      "messageText": "오늘 업무가 너무 많아서 힘들었어."
    }
    ```
  - **Response (200 OK)**:
    ```json
    {
      "success": true,
      "data": {
        "messageId": "msg_777",
        "responseText": "오늘 정말 고생 많으셨어요!",
        "motionTag": "COMFORT_WARM",
        "createdAt": "2026-08-05T16:31:00Z"
      }
    }
    ```
- **`DELETE /api/v3/chat/messages/{messageId}`**: 대화 메시지 소프트 삭제
- **`POST /api/v3/chat/messages/{messageId}/undo`**: 삭제 메시지 복구

### 3.6 대시보드 & 푸시 알림 API (`/api/v3/dashboard`, `/api/v3/notifications`)

#### 3.6.1 `GET /api/v3/dashboard/summary` [RPT-001]
- **설명**: 메인 화면에 표시할 상시 웰니스 차트 통계(칼로리, 수분, 운동량) 및 미션 수행 현황을 조회합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "data": {
      "todayWaterMl": 1500,
      "targetWaterMl": 2000,
      "todayCaloriesKcal": 1850,
      "targetCaloriesKcal": 2200,
      "completedMissions": 3,
      "totalMissions": 5
    }
  }
  ```

#### 3.6.2 `POST /api/v3/notifications/push-token` [RPT-003]
- **설명**: 별여행 탐사 완료 및 리포트 수령 시 발송되는 Push Notification 수신을 위해 클라이언트 앱에서 FCM/APNs 디바이스 푸시 토큰을 등록 및 갱신합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Request Body**:
  ```json
  {
    "deviceToken": "fcm_device_token_sample_xyz123",
    "deviceType": "IOS | ANDROID | WEB"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "디바이스 푸시 토큰이 성공적으로 등록되었습니다."
  }
  ```
