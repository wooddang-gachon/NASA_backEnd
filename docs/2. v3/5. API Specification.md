# TAMMY v3 백엔드 & AI 연동 통합 API 명세서 (API Specification)

본 문서는 TAMMY v3 서비스 백엔드(Node.js / Express / tsoa)의 외부 RESTful API 및 **FE (클라이언트) ↔ BE (백엔드) ↔ AI-server (LLM & Vision Engine)** 간 3자 오케스트레이션 프로토콜 통합 명세서입니다.

---

## 1. 개요 및 FE ↔ BE ↔ AI 3자 파이프라인 규약

### 1.1 기본 접속 정보 및 인증 규약
- **BE API Base URL**: `http://localhost:3000/api`
- **AI Server Base URL**: `http://ai-server:8000/v1` (FastAPI / LLM Engine 연동)
- **인증(Authentication)**: JWT Bearer Token 헤더 (`Authorization: Bearer <AccessToken>`)
- **공통 응답 래핑 규약 (`ApiResponse<T>`)**:
  모든 외부 RESTful API 응답은 `ApiResponse<T>` 형태로 일관되게 래핑되어 반환됩니다.
  ```json
  {
    "success": true,
    "message": "성공 응답 메시지",
    "data": { ... },
    "code": 200
  }
  ```

### 1.2 BE ↔ AI 연동 핵심 3대 흐름 (Architecture Flow)
1. **하이브리드 Food Vision 파이프라인**:
   - FE 사진 전송 (`POST /api/food-vision/scan`, Form-data field: `file`) ➔ BE에서 512x512 이미지 압축 ➔ BE 내장 YOLO 1차 검토 (명확 시 0원 처리) ➔ 미식별/불분명 시 AI-server (Vision LLM) 추가 스캔 ➔ FE 수동 검수 편집 카드 출력 ➔ FE 확정 저장 (`POST /api/food-log/confirm`)
2. **별여행 탐사 & AI 탐사 결과(travelResult) 동기 연동 파이프라인**:
   - 사용자가 연료(Fuel) 소진하여 5대 행성 탐사 출발 (`POST /api/planet-travel/start`) ➔ BE에서 연료 차감 후 최근 건강 수치 데이터 집계 ➔ AI-server로 탐사 결과 요약 생성 요청 (미구동 시 Fallback 탐사 결과 생성) ➔ DB 저장 및 `travelResultId`와 탐사 결과 반환
3. **AI 심리 공감 대화 & DB 선저장 파이프라인**:
   - FE 메시지 전송 (`POST /api/chat/message`) ➔ BE에서 DB에 메시지 즉시 저장 ➔ AI-server로 메시지 및 사용자 프로필 전달 ➔ AI-server 내부에서 공감 답변 및 관련 감정/웰니스 정보 종합 가공/정리 ➔ BE 수령 후 DB 저장 및 FE 반환

## 2. AI 서버 (tammy-agent) 연동 내부 프로토콜 스펙

* **내부 보안 헤더**: 모든 AI 서버 API 호출 시 `X-Internal-Api-Key: <INTERNAL_API_KEY>` 필수 전송.

### 2.1 [AI-001] 타미 대화 처리 및 감정 분석 API (`POST /v1/chat/process`)
- **BE ➔ AI 요청**:
  - `userId`: 유저 ID (number)
  - `userMessage`: 유저 메시지 (string)
  - `nickname`: 사용자 닉네임 (string, optional)
  - `history`: 이전 대화 기록 배열 (`ChatTurn` 배열, optional)
    - `role`: "user" | "tammy"
    - `text`: 대화 내용 (string)
    - `createdAt`: 일시 (string, optional)
- **AI ➔ BE 응답**:
  - `replyText`: 타미 심리 공감 응답 메시지 (string)
  - `emotion`: 감정 및 모션 정보 (object)
    - `state`: 감정 상태 (`HAPPY` | `SAD` | `ANGRY` | `STRESSED` | `CALM`)
    - `motionType`: 타미 캐릭터 반응 모션 태그 (`PAT_PAT_HEAD` 등)

### 2.2 [AI-002] 음식 이미지 분석 API (`POST /v1/vision/analyze-food`)
- **BE ➔ AI 요청**:
  - `imageUrl`: 이미지 공개 URL (string, optional)
  - `imageBase64`: Base64 인코딩 이미지 텍스트 (string, optional)
  - `mealType`: 식사 타입 (`BREAKFAST` | `LUNCH` | `DINNER` | `SNACK`)
- **AI ➔ BE 응답**:
  - `isIdentified`: 식별 여부 (boolean)
  - `comment`: 타미의 한마디 코멘트 (string)
  - `foods`: 인식된 음식 목록 배열
    - `name`: 음식명 (string)
    - `confidence`: 신뢰도 수치 0.0~1.0 (number)
    - `boundingBox`: 위치 좌표 (`x`, `y`, `width`, `height`)

### 2.3 [AI-003] 음식 영양성분 정보 조회 API (`POST /v1/nutrition/lookup`)
- **BE ➔ AI 요청**:
  - `foodNames`: 조회할 음식명 배열 (string[])
- **AI ➔ BE 응답**:
  - `items`: 영양 성분 결과 배열 (`name`, `servingSizeG`, `caloriesKcal`, `carbohydrateG`, `proteinG`, `fatG`, `vitaminPercent`, `mineralPercent`, `confidence`, `sources`)

### 2.4 [AI-004] 5대 행성 테마별 맞춤 탐사 결과 생성 API (`POST /v1/reports/*`)
- **행성별 엔드포인트 분기**:
  - **식단 행성 (`MEAL`)**: `POST /v1/reports/diet` (`userId`, `nickname`, `period`, `dailyRecords`)
  - **수분 행성 (`WATER`)**: `POST /v1/reports/hydration` (`userId`, `nickname`, `period`, `dailyGoalMl`, `waterLogs`)
  - **운동 행성 (`LIFESTYLE`)**: `POST /v1/reports/lifestyle` (`userId`, `nickname`, `period`, `exerciseLogs`, `dailySteps`)
  - **감정 행성 (`EMOTION`)**: `POST /v1/reports/mindfulness` (`userId`, `nickname`, `period`, `chatLogs`)
  - **회고별 행성 (`RETROSPECT`)**: `POST /v1/reports/retrospective` (`userId`, `nickname`, `period`, `waterLogs`, `exerciseLogs`, `dailyRecords`, `chatLogs` 종합)
- **AI ➔ BE 공통 응답**:
  - `title`: 탐사 결과 제목 (string)
  - `markdown`: AI 탐사 결과 마크다운 본문 (string)
  - `nextActionChecks`: 맞춤 추천 실행 가이드라인 배열 (string[])

## 3. 외부 백엔드 RESTful API 상세 스펙

### 3.1 회원 인증 & 계정 관리 API (`/api/auth`, `/api/users`)

#### 3.1.1 `POST /api/auth/register` (및 호환용 `POST /api/auth/signup`)
- **설명**: 이메일과 비밀번호 기반으로 신규 회원가입을 수행하고 초기 펫/우주선 상태를 생성한 뒤 JWT 토큰을 발급합니다.
- **Request Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!",
    "nickname": "우주탐험가",
    "gender": "MALE",
    "age": 25
  }
  ```
- **Response (201 Created)**:
  ```json
  {
    "success": true,
    "message": "회원가입이 성공적으로 완료되었습니다.",
    "data": {
      "user": {
        "id": 1,
        "email": "user@example.com",
        "nickname": "우주탐험가",
        "authProvider": "LOCAL"
      },
      "accessToken": "eyJhbGciOiJIUzI1Ni...",
      "refreshToken": "eyJhbGciOiJIUzI1Ni..."
    },
    "code": 201
  }
  ```

#### 3.1.2 `POST /api/auth/login`
- **설명**: 등록된 이메일과 비밀번호로 로그인하여 JWT Access Token과 Refresh Token을 발급받습니다.
- **Request Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "로그인이 성공적으로 완료되었습니다.",
    "data": {
      "user": {
        "id": 1,
        "email": "user@example.com",
        "nickname": "우주탐험가",
        "authProvider": "LOCAL"
      },
      "accessToken": "eyJhbGciOiJIUzI1Ni...",
      "refreshToken": "eyJhbGciOiJIUzI1Ni..."
    },
    "code": 200
  }
  ```

#### 3.1.3 `POST /api/auth/social-login`
- **설명**: 구글(Google), 카카오(Kakao), 애플(Apple) SDK에서 발급받은 OAuth 토큰을 검증하고, 미가입 시 자동 회원가입 처리 후 JWT 토큰을 발급합니다.
- **Request Body**:
  ```json
  {
    "provider": "GOOGLE | KAKAO | APPLE",
    "token": "ya29.a0AfH6SM...",
    "nickname": "우주탐험가"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "소셜 로그인이 성공적으로 완료되었습니다.",
    "data": {
      "user": {
        "id": 2,
        "email": "user@gmail.com",
        "nickname": "우주탐험가",
        "authProvider": "GOOGLE"
      },
      "accessToken": "eyJhbGciOiJIUzI1Ni...",
      "refreshToken": "eyJhbGciOiJIUzI1Ni..."
    },
    "code": 200
  }
  ```

#### 3.1.4 `POST /api/auth/refresh`
- **설명**: 만료된 Access Token을 재발급하기 위해 유효한 Refresh Token을 전달합니다.
- **Request Body**:
  ```json
  {
    "refreshToken": "eyJhbGciOiJIUzI1Ni..."
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "토큰이 성공적으로 갱신되었습니다.",
    "data": {
      "accessToken": "eyJhbGciOiJIUzI1Ni...",
      "refreshToken": "eyJhbGciOiJIUzI1Ni..."
    },
    "code": 200
  }
  ```

#### 3.1.5 `POST /api/auth/withdraw` (및 `DELETE /api/auth/withdraw`)
- **설명**: 회원 탈퇴를 처리하고 유저 상태를 변경하며 Refresh Token을 삭제합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Request Body** (선택):
  ```json
  {
    "reason": "서비스 이용 빈도 감소"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "회원 탈퇴가 완료되었습니다.",
    "data": {
      "userId": 1,
      "status": "WITHDRAWN"
    },
    "code": 200
  }
  ```

#### 3.1.6 `GET /api/users/me`
- **설명**: 현재 로그인한 사용자의 프로필 정보, 현재 보유 연료량(currentFuel) 및 펫(타미) 캐릭터 레벨/경험치 상태를 조회합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "내 프로필 및 타미 상태 조회가 완료되었습니다.",
    "data": {
      "userId": 1,
      "nickname": "우주탐험가",
      "gender": "FEMALE",
      "age": 25,
      "currentFuel": 250,
      "tammyStatus": {
        "level": 2,
        "currentExp": 120
      }
    },
    "code": 200
  }
  ```

#### 3.1.7 `GET /api/users/tammy/history`
- **설명**: 타미 캐릭터의 경험치 및 웰니스 지수 변동 성장 기록 히스토리를 조회합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "타미 성장 히스토리 조회가 완료되었습니다.",
    "data": {
      "logs": [
        {
  ```

### 3.3 Food Vision 스캔 & 기록 확정 API (`/api/food-vision`, `/api/food-log`)

#### 3.3.1 `POST /api/food-vision/scan`
- **설명**: 식단 사진 파일(`multipart/form-data`)을 업로드하여 AI 비전 모델로 5대 영양 성분을 스캔 분석합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Request Body (multipart/form-data)**:
  - `file`: 이미지 바이너리 파일 (필수)
  - `mealType`: 식사 타입 (`BREAKFAST` | `LUNCH` | `DINNER` | `SNACK`, 선택)
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "식단 이미지 업로드 및 분석이 성공적으로 완료되었습니다.",
    "data": {
      "scanEngine": "YOLO | VISION_LLM",
      "isFallbackUsed": false,
      "detectedFoods": [
        {
          "foodName": "제육볶음",
          "estimatedGram": 200,
          "calories": 350,
          "carbs": 12.5,
          "protein": 28.0,
          "fat": 18.2
        }
      ]
    },
    "code": 200
  }
  ```

#### 3.3.2 `POST /api/food-log/confirm`
- **설명**: 수동 검수 편집 카드를 통해 사용자가 최종 확정한 식단 영양 데이터를 DB에 저장합니다.

  ```json

    "success": true,
  ```

### 3.5 AI 타미 심리 공감 채팅 API (`/api/chat`)

#### 3.5.1 `POST /api/chat/message`
- **설명**: 사용자 메시지를 수신하여 DB 저장 후 AI-server로 전달, 심리 공감 답변 및 관련 모션 태그/연료를 반환합니다.
- **Header**: `Authorization: Bearer <AccessToken>`
- **Request Body**:
  ```json
  {
    "messageText": "오늘 업무가 너무 많아서 힘들었어."
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "message": "메시지가 성공적으로 전달되었습니다.",
  ```
