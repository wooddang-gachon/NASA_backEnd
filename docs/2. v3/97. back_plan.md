# 🚀 TAMMY Backend Plan (v3)

## 1. 개요 및 기술 스택 (Overview & Tech Stack)
본 문서는 TAMMY v3 서비스의 데이터 영속화, 상태 관리, AI 응답 검증 및 핵심 게임 루프 로직(우주 항해, 연료 보상, 타미 성장)을 제공하는 백엔드 서버의 종합 구축 계획서입니다.

- **서버 역할**: 클라이언트 접속 게이트웨이, SSE 실시간 스트리밍 중계, AI 분석 응답 검증 기반 DB 조작, 보상 엔진 및 100% MySQL RDB 전담 관리.
- **런타임 & 언어**: Node.js (v20+) & TypeScript (v5+)
- **웹 프레임워크 & API**: Express & TSOA (TypeScript OpenAPI / Swagger 자동 생성)
- **의존성 주입 (IoC)**: TypeDI
- **데이터베이스 & ORM**: MySQL 8.0+ & Prisma ORM (v7+)
- **로깅 & 디버깅**: Winston & Daily Rotate File
- **테스팅 스택**: Jest & ts-jest
- **프로젝트 구조**: Layered Architecture (API Router / Controller - Service - Model / Prisma DB Manager)

## 2. 데이터베이스 (DB) 스키마 계획

최신 `dbdiagram.dbml` 및 `7. erd.md` 스키마(총 27개 테이블, 8개 도메인)를 바탕으로 데이터 모델을 관리합니다.

### 2.1 사용자 & 타미 상태 (User & Tammy Status)
- `users`: 사용자 계정 마스터 (닉네임, 성별, 나이, 신체 목표, 선호 운동 정보 등)
- `tammy_statuses`: 타미 가상 펫 상태 (1:1 연동 - 레벨, 누적 EXP, 공감/건강/활동/행복 4대 지수)
- `user_body_logs`: 키, 체중 등 신체 변화 히스토리

### 2.2 대화 & 장기 기억 (Chat & Long-term Memory)
- `chat_messages`: 라이브 대화 메시지 (발신자, 본문, 수정 여부)
- `chat_message_edits`: 메시지 수정 히스토리
- `chat_message_archives`: AI 처리 원본 JSON 스냅샷이 포함된 영구 백업 대화 로그
- `long_term_memories`: AI가 추출한 사용자의 기피/선호 장기 기억 캡슐

### 2.3 영양 마스터 & 식단 케어 (Food & Meal Care)
- `foods`: 표준 음식 및 5대 영양소(칼로리, 탄/단/지, 비타민, 미네랄) 마스터 DB
- `meals`: 식단 기록 마스터 (식사 종류, 총 영양소 캐시, 코멘트)
- `meal_images`: 다중 식단 사진 (1:N)
- `meal_items`: 세부 섭취 음식 항목 (표준 음식 FK 또는 커스텀 음식명)

### 2.4 운동, 수분, 감정 다이어리 (Exercise, Water & Emotion)
- `exercises`: 운동 마스터 DB (MET 계수 포함)
- `exercise_logs`: 운동 실행 로그 (소모 칼로리 정밀 계산, 완료 여부)
- `water_logs`: 수분 섭취 로그 (기본 250ml)
- `emotion_logs`: 정서/스트레스 로그 (5개 감정 상태 및 사유)

### 2.5 우주 탐사 & 행성 (Space Travel & Planets)
- `planets`: 탐사 행성 마스터 (필요 연료량, 설명)
- `exercise_planets` / `nutrition_planets` / `emotion_planets` / `challenge_planets`: 4대 특화 행성 조건 (1:1 상속)
- `space_travel_states`: 사용자 항해 상태 (보유 연료량, 우주선 X/Y 좌표, 현재 행성 ID)
- `planet_histories`: 행성 도달/정복 이력 및 요약 코멘트

### 2.6 타임라인, 리포트 및 행동 로그 (Timeline, Report & Action Logs)
- `activity_logs`: 통합 타임라인 피드 스냅샷 JSON
- `proactive_triggers`: AI 선제적 톡 발화 큐 및 상태 관리
- `monthly_reports`: 월간 건강 집계 리포트 및 통계 데이터
- `user_action_logs`: 클라이언트 클릭스트림/행동 분석 로그
- `tammy_status_logs`: 타미 성장 및 경험치/속성 변동 히스토리 로그

## 3. 핵심 API 엔드포인트 설계

`5. apidocs.md` 및 백엔드 Gateway 구조를 기반으로 설계된 핵심 엔드포인트 목록입니다.

### 3.1 실시간 대화 & AI 응답 처리 API (`/chat`)
- `POST /chat/messages`:
  - 유저 발화 수신 ➔ AI 생성 요청.
  - **SSE 실시간 스트리밍**: AI 응답 텍스트를 중간 대기 없이 SSE 스트림으로 클라이언트에 즉시 전달.
  - **AI Action 데이터 처리**: AI가 수신된 발화에서 추출한 액션(LOG_WATER, LOG_EMOTION, LOG_WORKOUT 등)을 백엔드가 검증 후 MySQL DB 자동 적재 및 연료 보상 지급.
- `GET /chat/history`: 이전 대화 기록 목록 조회 (페이징)
- `GET /chat/memories`: 축적된 장기 기억 캡슐 목록 조회

### 3.2 식단 & 영양 분석 API (`/photo`, `/intake`)
- `POST /photo`: 식사 사진 업로드 (이미지 1024x1024 최적화 ➔ AI Vision 분석 중계 ➔ 영양 정보 수신 ➔ 식단 및 사진 DB 저장 ➔ 연료 +5% 보상)
- `POST /intake`: 빠른 감정/식사 텍스트 기록 입력 및 처리

### 3.3 운동 & 수분 & 감정 기록 API
- `POST /exercise/logs`: 운동 완료 기록 (MET 기반 칼로리 계산 ➔ 연료 +10% 보상 ➔ 타미 지수 갱신)
- `POST /water/logs`: 수분 섭취 기록
- `POST /emotion/logs`: 기분/스트레스 상태 기록

### 3.4 우주 항해 & 연료 API (`/travel`)
- `GET /travel/status`: 현재 누적 연료량, 우주선 좌표, 현재 및 목표 행성 진행도 조회
- `POST /travel/warp`: 행성 워프 및 연료 사용 처리 (연료 100 도달 시 행성 정복 히스토리 적재 및 좌표 이동)

### 3.5 월간 건강 리포트 API (`/report`)
- `GET /report`: 월간 건강 집계 데이터, 건강 점수 및 AI 생성 분석 리포트 조회

## 4. 백엔드 핵심 비즈니스 로직 구현 범위

1. **SSE Direct Pass-through & AI Action Engine**:
   - AI 응답 텍스트의 SSE 직통 스트리밍 처리.
   - AI가 추출한 Action Payload 데이터 검증 및 백엔드에서의 100% DB CRUD 제어.
2. **식단/일상 이미지 전처리 & 최적화 (Image Processing Engine)**:
   - 클라이언트에서 업로드한 식단 사진을 AI Vision API 및 스토리지에 전달하기 전 백엔드에서 사전 전처리.
   - **리사이징 & 압축**: 최대 해상도 `1024×1024` 이하 비율 다운스케이밍 및 WebP / JPEG (품질 80%) 압축 처리.
   - **효과**: 네트워크 전송 딜레이 타임 단축 및 Vision AI 토큰 소모량과 이미지 인코딩 비용 최적화.
3. **MET 공식을 활용한 운동 칼로리 계산**:
   - `소모 칼로리 = MET 계수 * 0.0175 * 최근 체중(kg) * 운동 시간(분)`
4. **연료 & 타미 성장 트랜잭션 (Reward Engine)**:
   - 식단 등록(+5%), 운동 완료(+10%) 등에 따른 연료 충전 및 EXP/지수 변동 로직.
   - 변동 내역을 `tammy_status_logs`에 스냅샷으로 기록하여 투명한 히스토리 제공.
5. **월간 통계 데이터 캐싱 및 집계**:
   - 식단(탄/단/지), 운동 시간, 수분/감정 로그를 집계하여 `monthly_reports`에 JSON 캐싱.

## 5. 단계별 개발 이행 로드맵 (Development Roadmap)

1. **1단계 (기반 구축 & DB 스키마)**:
   - Express + TypeScript + TSOA + TypeDI 백엔드 세팅.
   - `schema.sql` 및 Prisma ORM을 통한 MySQL DB 스키마 마이그레이션.
2. **2단계 (핵심 컨트롤러 & 서비스)**:
   - `authService`, `userService`, `exerciseService`, `foodService`, `travelService` 구현.
3. **3단계 (AI 연동 & SSE 스트리밍 게이트웨이)**:
   - `aiService` 및 `chatService` 구현 (SSE 직통 파이프라인 + AI Action JSON 검증 및 DB 적재).
4. **4단계 (보상 엔진 & 통계 집계)**:
   - `travelService` 연료 충전/워프 트랜잭션 및 `reportService` 월간 리포트 집계 구현.
5. **5단계 (검증 & 통합 테스트)**:
   - Jest 단체 테스트 및 Swagger OpenAPI 문서를 통한 시뮬레이션 검증.
