# TAMMY v3 백엔드 API & AI 서버 3자 연동 명세서 (BE ↔ AI Server Protocols)

본 문서는 TAMMY v3 서비스 백엔드(Node.js / Express / TSOA)의 외부 RESTful API 및 **FE (클라이언트) ↔ BE (백엔드) ↔ AI (tammy-agent AI 모델 서버)** 간 3자 오케스트레이션 프로토콜 및 데이터 모델 명세서입니다.

---

## 1. 개요 및 FE ↔ BE ↔ AI 3자 파이프라인 규약

### 1.1 기본 접속 정보 및 인증 규약
- **BE API Base URL**: `http://localhost:3000/api` (Swagger UI: `/api/docs`)
- **AI Server Base URL**: `http://ai-server:8000/v1` (tammy-agent FastAPI Swagger Spec 연동)
- **인증(Authentication)**: JWT Bearer Token 헤더 (`Authorization: Bearer <AccessToken>`) 사용

### 1.2 BE ↔ AI 연동 핵심 3대 흐름 (Architecture Flow)
1. **음식 이미지 스캔 & 식사 일기 (Meal Log & Diary Flow)**:
   - FE 사진 스캔 ➔ BE가 AI 비전 분석 호출 ➔ 음식명 추출 ➔ 유저가 100자 이내 식사 일기(`diary`) 작성 ➔ 식단 확정 ➔ 작성된 일기가 타미 대화 맥락으로 자동 입력되어 심리 대화 물꼬 트기
2. **AI 대화 & 기억 캡슐 압축 (Chat & Memory Compression Flow)**:
   - FE 대화 전송 ➔ BE가 기억 맥락(`memory`) 및 대화 이력을 포함하여 AI 호출 ➔ AI가 공감 응답 및 핵심 장기 기억 선별/추가
3. **AI 3종 리포트 생성 (AI 3-Type Report Pipeline)**:
   - 비동기 생성 요청 ➔ 백그라운드 Worker가 식사 일기, 섭취 기록, 운동/활동 기록, 대화 기억 집계 ➔ AI 3종 리포트 생성 ➔ Push Notification 발송

## 2. AI 서버 (tammy-agent) 연동 내부 프로토콜 스펙

### 2.1 [AI-001] 음식 이미지 비전 분석 API (`POST http://ai-server:8000/v1/vision/analyze-food`)
- **BE ➔ AI 요청**:
  - `imageUrl`: 업로드된 음식 사진 URL
  - `mealType`: 식사 종류 (BREAKFAST | LUNCH | DINNER | SNACK)
- **AI ➔ BE 응답**:
  - `isIdentified`: 인식 여부 (boolean)
  - `foodName`: 식별된 음식명
  - `nutrients`: 4대 영양소 + 미량 영양소 구조 (`caloriesKcal`, `carbohydrateG`, `proteinG`, `fatG`, `additionalProp...`)
  - `comment`: AI 영양 피드백 소평

### 2.2 [AI-002] 심리 대화 & 기억 추출 API (`POST http://ai-server:8000/v1/chat/process`)
- **BE ➔ AI 요청**:
  - `userId`: 유저 ID
  - `userMessage`: 유저 대화 메시지 (식사 일기 연동 포함)
  - `memory`: 대화 맥락 및 기억 구조체
    - `today`: 오늘 날짜
    - `weather`: 날씨 정보
    - `tammy`: `{ "name": "타미", "level": 1, "days_together": 10 }`
    - `recent_records`: 압축된 대화 및 주요 기억 문장 배열
- **AI ➔ BE 응답**:
  - `replyText`: 타미 공감 응답 메시지
  - `emotion`: `{ "state": "HAPPY", "motionType": "BOUNCE" }`
  - `newMemoryContent`: 새로 선별된 장기 기억 캡슐 (Optional)

### 2.3 [AI-003] 3종 건강/심리 리포트 생성 API (`POST http://ai-server:8000/v1/reports/summarize`)
- **BE ➔ AI 요청 (통합 집계 페이로드)**:
  - `user_id`: 유저 식별자
  - `report_type`: 리포트 3종 유형 (`WELLNESS` | `MINDFULNESS_DIARY` | `COMPREHENSIVE_NUTRITION_EXERCISE`)
  - `period_from`: 시작 일자 (`YYYY-MM-DD`)
  - `period_to`: 종료 일자 (`YYYY-MM-DD`)
  - `entries` (식사 일기 및 식단 기록 목록):
    - `meal_id`: 식사 기록 ID
    - `recorded_at`: 기록 시각
    - `foods`: 포함된 음식명 배열 (`["연어 샐러드", "아메리카노"]`)
    - `diary`: 100자 내외 식사 일기 텍스트 ("오늘 업무 스트레스로 매운 게 당겼지만 샐러드로 참아냄!")
  - `activities` (운동 및 신체 활동 기록):
    - `id`: 활동 ID
    - `date`: 수행 일자
    - `type`: 활동 유형 (`WORKOUT`, `WALK`, `STRETCHING`)
    - `duration_minutes`: 활동 지속 시간 (분)
    - `note`: 메모
  - `other_intakes` (수분 및 기타 섭취 기록):
    - `id`: 섭취 ID
    - `recorded_at`: 섭취 시각
    - `type`: 섭취 유형 (`WATER`, `SNACK`, `SUPPLEMENT`)
    - `value`: 섭취량 수치
    - `unit`: 단위 (`ml`, `g`, `count`)
- **AI ➔ BE 응답**:
  - `report_id`: AI 리포트 식별자
  - `summary`: 진단 요약문
  - `wellness_score`: 웰니스 종합 점수 (0~100)
  - `mindfulness_feedback`: 식사 일기 기반 심리 상태 분석 코멘트
  - `recommendations`: 맞춤 가이드라인 추천 배열

## 3. 외부 백엔드 RESTful API 상세

### 3.1 [FOD Module] 비전 스캔 & 식단 확정 + 식사 일기 (Meal Log & Diary)

#### `POST /api/food/analyze` (음식 사진 AI 비전 스캔)
- **Query Parameters**: `imageUrl` (string), `mealType` (BREAKFAST | LUNCH | DINNER | SNACK)
- **Response Body**:
  - `isIdentified`: true
  - `foodName`: "연어 샐러드"
  - `totalCaloriesKcal`: 380
  - `carbohydrateG`: 14.5
  - `proteinG`: 32.0
  - `fatG`: 11.2
  - `comment`: "단백질과 비타민이 풍부한 최고 웰니스 식단입니다!"

#### `POST /api/food/log` (식단 확정 등록 + 식사 일기 및 대화 물꼬 연동)
- **Query Parameter**: `userId` (number)
- **Request Body**:
  - `mealType`: "LUNCH"
  - `foodName`: "연어 샐러드"
  - `totalCaloriesKcal`: 380
  - `carbohydrateG`: 14.5
  - `proteinG`: 32.0
  - `fatG`: 11.2
  - `imageUrls`: `["https://storage.tammy.app/salad.jpg"]`
  - `diary`: "오늘 업무 스트레스로 너무 지쳤지만 나를 위해 건강한 연어 샐러드를 챙겨 먹었다 🥗" (100자 이내 식사 일기)
- **Response Body**:
  - `logId`: 1
  - `gainedFuel`: 50
  - `gainedExp`: 30
  - `currentFuel`: 160
  - `autoChatTriggered`: true
  - `tammyChatReply`: "오늘 스트레스받는 와중에도 자신을 위해 건강한 샐러드를 챙겨 드셨다니 정말 대견해요! 오늘 하루 많이 힘들었나요?" (식사 일기 기반 타미의 자동 대화 물꼬 응답)

#### `GET /api/food/search` (표준 음식 영양 마스터 검색)
- **Query Parameter**: `keyword` (string)
- **Response Body**: 음식 영양성분 마스터 데이터 배열 반환

---

### 3.2 [CHT Module] AI 심리 대화 & 장기 기억 캡슐 (Chat & Memory)

#### `POST /api/ai/chat` (AI 타미 심리 대화)
- **Query Parameter**: `userId` (number)
- **Request Body**: `{ "message": "오늘 다이어트가 너무 힘들어서 치킨 먹고 싶어 😭" }`
- **Response Body**:
  - `reply`: "다이어트 중 느끼는 서러움은 너무 자연스러워요! 오늘 하루 노력한 스스로를 위해 물 한 잔 마시고 가벼운 산책 어떨까요?"
  - `emotion`: "STRESSED"
  - `gainedFuel`: 10
  - `currentFuel`: 170

#### `GET /api/chat/memories` (장기 기억 캡슐 목록 조회)
- **Query Parameter**: `userId` (number)
- **Response Body**: 유저의 장기 기억 캡슐 배열 반환

#### `DELETE /api/chat/memories/:id` (장기 기억 캡슐 삭제)
- **Response Body**: `{ "success": true }`

---

### 3.3 [TRV / CARE / WKO Module] 별여행 & 1-Tap 데일리 케어 (Activities & Other Intakes)

#### `POST /api/care/water` (1-Tap 수분 섭취 250ml)
- **Request Body**: `{ "userId": 1, "intakeMl": 250 }`
- **Response Body**: `{ "todayTotalWaterMl": 500, "gainedFuel": 10, "currentFuel": 180 }`

#### `POST /api/exercise/log` (1-Tap 오늘 운동 완! 및 활동 기록)
- **Request Body**: `{ "userId": 1, "activityType": "WORKOUT", "durationMinutes": 30, "memo": "스쿼트 20회 & 러닝 완료" }`
- **Response Body**: `{ "workoutLogId": 1, "gainedFuel": 30, "currentFuel": 210 }`

#### `GET /api/travel/state` (우주선 & 별여행 탐사 상태 조회)
- **Response Body**: 현재 행성 명칭, 탐사 진척도(%), 보유 연료 반환

#### `POST /api/travel/fuel` (미션 보상 연료 직접 충전 & 워프 검사)
- **Response Body**: 충전 결과 및 행성 워프 여부(`isWarped`) 반환

---

### 3.4 [RPT / NTF Module] 3종 건강 리포트 & 푸시 알림

#### `GET /api/reports/dashboard` (상시 웰니스 대시보드 데이터 조회)
- **Response Body**: 5대 영양소 밸런스, 일간 칼로리 추이, 운동 달성률 차트 데이터 반환

#### `POST /api/reports/generate` (AI 3종 리포트 비동기 생성 요청)
- **Query Parameter**: `userId` (number)
- **Request Body**:
  - `reportType`: "WELLNESS" | "MINDFULNESS_DIARY" | "COMPREHENSIVE_NUTRITION_EXERCISE"
  - `periodFrom`: "2026-08-01"
  - `periodTo`: "2026-08-07"
- **Response Status**: `202 Accepted`
- **Response Body**: `{ "jobId": "rpt_job_20260804_001", "status": "PENDING", "message": "리포트 생성이 비동기로 시작되었습니다." }`

#### `GET /api/reports/jobs/:jobId` (리포트 백그라운드 생성 상태 조회)
- **Response Body**: 작업 진행도 및 상태 반환

#### `GET /api/reports/:reportId` (생성 완료된 리포트 상세 조회)
- **Response Body**: 3종 리포트 진단 결과 및 AI 심리 피드백 코멘트 반환

#### `POST /api/notifications/push-token` (Push Notification 디바이스 토큰 등록)
- **Request Body**: `{ "deviceToken": "fcm_token_12345", "platform": "IOS" }`
- **Response Body**: `{ "success": true }`

### 3.5 [ATH / USR / LOG Module] 인증 & 프로필 & 행동 분석

- `POST /api/auth/signup`: 이메일 회원가입 및 초기 펫/우주선 자동 생성
- `POST /api/auth/login`: 로그인 및 JWT 토큰 발급
- `POST /api/auth/logout`: 로그아웃 세션 무효화
- `POST /api/auth/refresh`: Access Token 재발급
- `GET /api/auth/me`: 내 계정 인증 정보 조회
- `DELETE /api/auth/withdraw`: 회원 탈퇴
- `GET /api/users/me`: 내 프로필 및 타미 펫 상태 통합 조회
- `GET /api/users/tammy/history`: 타미 성장 히스토리 조회
- `POST /api/logs/action`: 사용자 행동 이벤트 비동기 배치 수집
