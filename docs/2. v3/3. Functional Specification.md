# TAMMY v3 기능 정의서 (Functional Specification)

## 1. 개요 (Overview)

- **서비스명**: TAMMY v3 (AI 타미 메이트 기반 심리 공감 & 웰니스 별여행)
- **분석 및 기반**: `demo/TAMMY v3.html`, `decision.md` 의사결정 사항 반영
- **핵심 목표**: AI 타미 캐릭터의 **심리 공감 대화**, **사진 촬영 기반 AI 분석**, **1-Tap 퀵버튼 기록**, 그리고 **타미 별여행 게이미피케이션**을 중심으로 사용자에게 부담 없는 지속 가능한 맞춤형 웰니스 경험을 제공하는 통합 기능 명세서

---

## 2. 핵심 서비스 축 (Core Pillars)

1. **AI 타미 심리 공감 채팅**: 대화 맥락 및 감정 분석, 기억 캡슐(Memory Pill) 기반의 개인화 심리 케어
2. **1-Tap 퀵버튼 (기능 실행 & 기록)**: 빠른 사진 촬영, 리포트 생성 및 물/감정/감정일기/운동의 원터치 단축 기록
3. **사진 촬영 & AI 서버 분석**: BE 이미지 압축, 자체 경량 YOLO 1차 검토 및 필요시 Vision LLM Fallback을 통한 영양/웰니스 데이터 트래킹
4. **타미 별여행 게이미피케이션**: 미션 수행을 통한 연료(Fuel) 충전, 5대 행성(식사, 수분, 감정, 생활습관, 회고) 탐사 및 별여행 완료 시 맞춤 리포트 수령

---

## 3. 기능 세부 명세 (Feature Specifications)

### 3.1 AI 타미 심리 공감 채팅 (AI Empathy Chatbot)

- **[CHT-001] AI 타미 심리 공감 & 감정 반응**
  - **Depth / 분류**: 심리 공감 > 채팅 > 감정 반응 및 종합 가공
  - **상세 설명 / 동작 로직**: 메시지 수신 즉시 BE에서 사용자 메시지를 DB에 저장한 뒤 AI-server로 전송. AI-server 내부에서 심리 공감 응답 및 관련 웰니스/감정 정보를 종합 가공/정리하여 BE로 전달 후, BE가 DB 저장 및 FE에 최종 응답을 반환
  - **비고 / 이슈**: DB 즉시 저장 및 AI-server 종합 가공 처리 파이프라인 구축

- **[CHT-002] 대화 데이터 관리 & 개인정보보호**
  - **Depth / 분류**: 심리 공감 > 대화 관리 > 저장 및 삭제
  - **상세 설명 / 동작 로직**: 채팅 기록의 안전한 관리, 개별 대화 내역 삭제 및 실수로 삭제 시 복구 가능한 Undo Toast 기능 지원
  - **비고 / 이슈**: 로컬 DB/Storage 타임아웃 및 Undo 토스트 처리

---

### 3.2 1-Tap 퀵버튼 체계 (1-Tap Quick Actions & Logging)

- **[QCK-001] 1-Tap 퀵버튼 기능 실행 (Quick Actions)**
  - **Depth / 분류**: 1-Tap 퀵버튼 > 기능 실행
  - **상세 설명 / 동작 로직**:
    - **사진 촬영**: 식단/웰니스 사진 촬영 및 멀티모달 Vision AI 전송 모듈 즉시 실행
    - **리포트 생성**: 축적된 대화 및 건강 기록 데이터를 바탕으로 AI 종합 인사이트 리포트 생성 요청
  - **비고 / 이슈**: 클릭 시 프롬프트 자동 입력 및 각 해당 기능 즉시 진입

- **[QCK-002] 1-Tap 퀵버튼 데일리 기록 (Quick Logging)**
  - **Depth / 분류**: 1-Tap 퀵버튼 > 기록
  - **상세 설명 / 동작 로직**:
    - **물 기록**: 일일 수분 목표 대비 잔 수량 원터치 단축 입력
    - **감정 기록**: 현재 기분/감정 상태 선택 및 탭 기록
    - **감정일기**: 일일 회고 및 상세 감정 텍스트/음성 기록 창 진입
    - **운동 기록**: 무슨 운동을 했는지 별도 구분 없이 1-Tap 원터치 운동 수행/시간 단순 기록
  - **비고 / 이슈**: 카운터 UI 및 간편 폼 모달 연동

---

### 3.3 사진 촬영 & AI 서버 분석 (Photo Vision & Wellness)

- **[FOD-001] 사진 촬영 & BE 1차 검토 및 Fallback 스캔**
  - **Depth / 분류**: AI 비전 스캔 > 사진 촬영 > BE 1차 검토 및 Fallback
  - **상세 설명 / 동작 로직**: 카메라 촬영 또는 갤러리 이미지 선택 시 BE에서 이미지 리사이징 & 압축(512x512 Low-Res)을 수행한 뒤, 자체 경량 YOLO 모델로 1차 음식 식별 수행. 인식 성공 시 즉시 결과를 반환하고, 미식별/불분명 시에만 AI-server(Vision LLM)로 Fallback 추가 분석 요청
  - **비고 / 이슈**: BE 이미지 압축, YOLO 1차 검토 및 Vision LLM Fallback 연동

- **[FOD-002] 스캔 예외 처리 & Fallback UI**
  - **Depth / 분류**: AI 비전 스캔 > 예외 처리 > Fallback UI
  - **상세 설명 / 동작 로직**: 사진 인식 실패(피사체 불분명, 음식 미식별 등) 시 Toast 알림과 함께 '다시 촬영하기' 및 '수동 음식 검색/입력' Fallback UI 즉시 제공
  - **비고 / 이슈**: 예외 발생 시 UX 연동 보장

- **[FOD-003] 사진 기반 칼로리 & 3대 영양소 트래킹**
  - **Depth / 분류**: AI 비전 스캔 > 영양 분석 > 칼로리 및 영양소
  - **상세 설명 / 동작 로직**: 인식된 사진 데이터를 기반으로 칼로리 및 3대 영양소(탄수화물, 단백질, 지방) 함량 분석
  - **비고 / 이슈**: 3대 영양소 DB 산출 및 영양 밸런스 데이터 연동

- **[FOD-004] 분석 결과 수동 검수 & 편집 카드**
  - **Depth / 분류**: AI 비전 스캔 > 데이터 검수 > 수동 편집
  - **상세 설명 / 동작 로직**: AI가 분석한 결과를 사용자가 확인하고 수량을 수정하거나 항목을 추가/삭제할 수 있는 검수 카드 UI 제공
  - **비고 / 이슈**: 수동 편집 시 칼로리 및 영양성분 즉시 재계산

---

### 3.4 타미 별여행 게이미피케이션 (Planet Travel & Growth)

- **[GAM-001] 우주/행성 탐사 & 별여행 리포트 수령**
  - **Depth / 분류**: 게이미피케이션 > 별여행 > 행성 탐사 및 리포트
  - **상세 설명 / 동작 로직**:
    - 일상 기록(식단, 수분, 감정, 운동 등) 및 1-Tap 퀵버튼 미션 수행으로 '연료(Fuel)'를 충전하고, 충전된 연료를 사용해 원하는 행성(타미별)으로 별여행 탐사를 출발합니다.
    - 별여행 탐사를 마치고 돌아오면 해당 행성의 주제에 특화된 **AI 맞춤 리포트**를 수령합니다.
    - **행성(타미별) 구성**:
      - **식사별**: 식단 기록 및 영양 밸런스 기반 분석 리포트 수령
      - **수분별**: 수분 섭취 패턴 및 목표 달성도 분석 리포트 수령
      - **감정별**: 감정 기록 및 감정일기 기반 심리 상태 분석 리포트 수령
      - **생활습관별**: 운동 및 데일리 웰니스 패턴 분석 리포트 수령
      - **회고별 (자동 실행)**: 특정 기간(주간/월간 등)마다 자동으로 별여행이 실행되어 기간 종합 회고 리포트 수령
  - **비고 / 이슈**: 연료 획득/소진 알고리즘, 행성별 맞춤 리포트 생성 Worker 연동 및 회고별 자동 실행 스케줄러 구축

### 3.5 건강 인사이트 & 종합 리포트 (Insight & Care)

- **[RPT-001] 상시 웰니스 대시보드 (Wellness Dashboard)**
  - **Depth / 분류**: 건강 인사이트 > 통계 > 대시보드
  - **상세 설명 / 동작 로직**: 메인 탭에서 칼로리 추이(선 차트), 영양소 밸런스, 미션 수행 유무를 상시 시각화 그래프로 확인
  - **비고 / 이슈**: 차트 라이브러리 연동 및 누적 통계 API 호출

- **[RPT-003] 리포트 생성 완료 푸시 알림 (Push Notification)**
  - **Depth / 분류**: 건강 인사이트 > 알림 > 푸시 알림
  - **상세 설명 / 동작 로직**: 별여행 복귀 또는 백그라운드 작업으로 리포트 생성이 완료되면 Push Notification 완료 알림을 발송하고, 알림 클릭 시 리포트 상세 화면으로 이동
  - **비고 / 이슈**: Push Notification 서비스 (FCM / APNs) 연동 및 딥링크(Deep Link) 이동 처리

- **[CARE-001] 마이페이지 & 서비스 설정**
  - **Depth / 분류**: 서비스 관리 > 마이페이지 > 시스템 설정
  - **상세 설명 / 동작 로직**: TTS 음성 토글, 알림/방해금지(DND) 설정, 수집된 AI 기억 캡슐 종합 관리
  - **비고 / 이슈**: 마이페이지 사용자 설정 DB 저장

### 3.6 회원 인증 & 계정 관리 (Auth & User Management)

- **[ATH-001] 이메일 & 소셜 회원가입**
  - **Depth / 분류**: 계정 관리 > 회원가입 > 이메일 및 소셜
  - **상세 설명 / 동작 로직**: 이메일/비밀번호 또는 소셜 연동(카카오, 구글, 애플)을 통해 신규 계정을 생성하고 기본 프로필(닉네임, 수분/칼로리 목표) 설정
  - **비고 / 이슈**: 비밀번호 암호화(bcrypt/argon2) 및 이메일 중복 검사

- **[ATH-002] 로그인 & JWT 인증 토큰 발급**
  - **Depth / 분류**: 계정 관리 > 로그인 > JWT 인증
  - **상세 설명 / 동작 로직**: OAuth 2.0 및 로그인 시 백엔드에서 Access Token과 Refresh Token을 발급하여 안전한 API 통신 지원
  - **비고 / 이슈**: JWT 인증 미들웨어 구축 및 HTTP-only Cookie/Secure Storage 저장

- **[ATH-003] 로그아웃 & 토큰 무효화**
  - **Depth / 분류**: 계정 관리 > 로그아웃 > 세션 만료
  - **상세 설명 / 동작 로직**: 로그아웃 요청 시 서버 DB/Redis의 Refresh Token을 삭제/블랙리스트 처리하고 클라이언트 기기 내 세션/토큰 제거
  - **비고 / 이슈**: Refresh Token DB 즉시 만료 및 보안 처리

- **[ATH-004] Access Token 자동 갱신 (Token Refresh)**
  - **Depth / 분류**: 계정 관리 > 인증 > 토큰 갱신
  - **상세 설명 / 동작 로직**: Access Token 만료 시 클라이언트 인터셉터를 통해 저장된 Refresh Token으로 새로운 Access Token을 자동 재발급
  - **비고 / 이슈**: Axios/Fetch Interceptor 자동 재시도 로직 구현

- **[ATH-005] 회원 탈퇴 & 데이터 관리**
  - **Depth / 분류**: 계정 관리 > 회원 탈퇴 > 데이터 익명화 및 삭제
  - **상세 설명 / 동작 로직**: 회원 탈퇴 요청 시 사용자 상태를 WITHDRAWN으로 변경하고 관련 개인정보 및 건강/대화 데이터를 익명화 또는 지연 삭제
  - **비고 / 이슈**: 개인정보보호법에 따른 익명화 및 데이터 보관 유예 정책 적용
