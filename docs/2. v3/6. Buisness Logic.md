## 📌 2. 별여행 게이미피케이션

### 행성 구성 (`PLANET_CONFIGS`)

| 행성 타입 | 행성 이름 | 목표 거리 |
|----------|----------|----------|
| `MEAL` | 식단 탐사 별 | 100 |
| `WATER` | 수분 탐사 별 | 100 |
| `EMOTION` | 감정 대화 별 | 100 |
| `LIFESTYLE` | 라이프스타일 별 | 100 |
| `RETROSPECT` | 회고 별 | 100 |

### 핵심 상수

| 상수 | 값 | 설명 |
|------|-----|------|
| `TOTAL_STAR_COUNT` | 5 | 전체 행성 수 |
| `TOTAL_TARGET_DISTANCE` | 500 | 탐사 총 목표 거리 |
| `WARP_FUEL_THRESHOLD` | 300 | 다음 행성 워프에 필요한 연료 |
| `REPORT_FUEL_COST` | 100 | 온디맨드 리포트 생성 시 소모 연료 |

### 탐사 진행 규칙
1. 탐사 출발 시 해당 행성의 `required_fuel` 만큼 연료 차감
2. 행성별 액션 횟수가 `targetDistance`(100)에 도달하면 탐사 완료
3. 탐사 완료 시 AI 진단서 자동 생성 (AiService.generatePlanetReport)
4. 중복 진행 불가 — 이미 `IN_PROGRESS`인 탐사가 있으면 `400 ALREADY_IN_PROGRESS_TRAVEL`

### 탐사 진행률 계산
```
totalAchieved = 각 행성 currentDistance의 합
progressPercent = min(floor(totalAchieved / TOTAL_TARGET_DISTANCE * 100), 100)
```

## 📌 4. AI 대화 처리 흐름

```
사용자 메시지 입력
    │
    ▼
1. 사용자 존재 확인 (없으면 404 USER_NOT_FOUND)
2. 사용자 메시지 DB 저장 (sender: USER)
3. 최근 10개 대화 히스토리 조회 (user/tammy)
    │  ※ 조회 실패 시 빈 배열로 Graceful degradation
    │
    ▼
4. AI 서버에 대화 요청 (POST /v1/chat/process)
    │  - 페이로드: userId, userMessage, nickname, history
    │  - 인증: X-Internal-Api-Key 헤더
    │
    ▼
AI 응답 수신 (AiChatInternalResponse)
    ├── reply (응답 메시지)
    ├── emotion (감정 상태)
    ├── motionTag (모션 태그)
    ├── intentLabel (인텐트 라벨)
    └── extractedMemory (메모리 캡슐)
    │
    ▼
5. AI 응답 메시지 DB 저장 (sender: TAMMY_AI)
    │  - emotion, motion_tag, intent_label, labels 함께 저장
6. 메모리 캡슐 별도 저장 (있는 경우)
7. 사용자 연료 +10 적립 (FUEL_REWARDS.CHAT)
```

- 자동 생성 절대 금지
- 적용 서비스: AuthService, ChatService, FoodService, QuickLogService, TravelService, UserService

## 📌 6. 에러 처리 체계

### 커스텀 에러 클래스 계층

| 에러 클래스 | HTTP 코드 | 사용처 |
|------------|----------|--------|
| `AppError` | 가변 | 기본 커스텀 에러 (code, status, details) |
| `BadRequestError` | 400 | 유효성 검증 실패, 연료 부족, 중복 탐사 |
| `UnauthorizedError` | 401 | 토큰 만료, 잘못된 비밀번호, 미인증 |
| `ForbiddenError` | 403 | 접근 권한 없음 |
| `NotFoundError` | 404 | 리소스 미존재 |
| `UserNotFoundError` | 404 | 사용자 미존재 (NotFoundError 상속) |
| `ConflictError` | 409 | 중복 이메일 가입 |
| `BadGatewayError` | 502 | 소셜 인증 실패 |
| `AiServerError` | 503 | AI 서버 통신 장애 |
| `InternalServerError` | 500 | 미처리 예외 |

### 전역 에러 핸들러 처리 흐름
1. `AppError` → err.status 코드로 응답
2. `ValidateError` (TSOA) → 400 `VALIDATION_ERROR`
3. 기타 미처리 예외 → 500 `INTERNAL_SERVER_ERROR` (스택 트레이스 은닉)

| 스케줄 | 작업 | 설명 |
|--------|------|------|

## 📌 8. 비동기 작업 큐 (AsyncQueue)

- 싱글톤 `reportQueue` 인스턴스 제공 (리포트 생성 등 중작업용)
