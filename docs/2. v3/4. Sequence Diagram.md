# TAMMY v3 시퀀스 다이어그램 (Sequence Diagrams)

본 문서는 FE, BE, DB, AI-server 간의 데이터 흐름과 시스템 간 인터랙션을 정의합니다.

---

## 1. 1-Tap 퀵버튼 기록 & 연료(Fuel) 충전 시퀀스

사용자가 1-Tap 퀵버튼으로 데일리 웰니스 항목을 기록하고 연료(Fuel)를 적립하는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)

    User->>FE: 1-Tap 퀵버튼 클릭 (물/감정/일기/운동)
    FE->>BE: POST /api/v3/quick-log (기록 데이터)
    BE->>DB: 기록 저장 (Water/Emotion/Journal/Exercise)
    BE->>DB: 사용자 연료(Fuel) 계산 및 포인트 적립 (+10 Fuel)
    DB-->>BE: 저장 완료 및 갱신된 Fuel 반환
    BE-->>FE: HTTP 200 OK (기록 성공, Total Fuel)
    FE-->>User: Toast 알림 ("기록 완료! 연료 +10 충전") & UI 갱신
```

## 2. 별여행 탐사 & 비동기 AI 리포트 생성 및 푸시 알림 시퀀스

연료를 소진하여 별여행 탐사를 출발하고, AI-server가 행성 맞춤 리포트를 백그라운드에서 생성하여 푸시 알림으로 수령하는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)
    participant AI as AI-server (LLM Engine)

    User->>FE: 탐사 행성 선택 (식사/수분/감정/생활습관) 및 '별여행 출발' 클릭
    FE->>BE: POST /api/v3/planet-travel/start { planetType, fuelSpent }
    BE->>DB: 연료(Fuel) 차감 & 탐사 상태(IN_PROGRESS) 저장
    BE-->>FE: HTTP 202 Accepted (탐사 시작 응답)
    FE-->>User: "별여행 출발! 완료 시 리포트를 보내드려요." 안내 UI 표시

    Note over BE, AI: 백그라운드 비동기 리포트 생성 작업
    BE->>DB: 해당 행성 테마의 최근 기록 데이터 조회
    DB-->>BE: 섭취/감정/습관 데이터 반환
    BE->>AI: 행성 맞춤 리포트 생성 요청 (Prompt + History Data)
    AI-->>BE: LLM 생성 맞춤 리포트 JSON 응답
    BE->>DB: 별여행 완료(COMPLETED) 상태 갱신 및 리포트 저장
    BE->>FE: Push Notification 알림 발송 ("별여행 복귀! 탐사 리포트 도착")
    
    User->>FE: 푸시 알림 클릭
    FE->>BE: GET /api/v3/reports/{reportId}
    BE->>DB: 리포트 상세 데이터 조회
    DB-->>BE: Report Detail Data
    BE-->>FE: HTTP 200 OK
    FE-->>User: 행성 맞춤 AI 리포트 상세 화면 표시
```

## 3. 사진 촬영 & Food Vision AI 영양 스캔 및 수동 검수 시퀀스

식단 사진 촬영 후 **BE 서버에서 이미지 압축** 및 **자체 경량 YOLO 모델로 1차 검토**를 수행하며, 인식이 불분명하거나 미식별 시에만 **AI-server(Vision LLM)로 추가 분석 요청**을 보내는 2단계 하이브리드 비전 흐름입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server + YOLO)
    participant DB as DB (Main DB)
    participant AI as AI-server (Vision LLM)

    User->>FE: 식단 사진 촬영 또는 갤러리 이미지 선택
    FE->>BE: POST /api/v3/food-vision/scan (Original Image File)
    BE->>BE: 이미지 리사이징 & 압축 (512x512 Low-Res)
    BE->>BE: 자체 경량 YOLO 모델로 1차 음식 식별 & 검토

    alt 1. YOLO 1차 검토 결과가 명확한 경우 (정상 인식)
        Note over BE: 외부 API 호출 0원으로 즉시 빠른 처리
        BE-->>FE: HTTP 200 OK (YOLO 식별 음식 & 영양 데이터)
    else 2. YOLO 검토 결과가 미식별 / 불분명한 경우 (Fallback)
        BE->>AI: 멀티모달 Vision LLM 스캔 요청 (Batch Prompt + 압축 이미지)
        AI-->>BE: 음식 식별 태그 및 영양성분 추정 JSON 응답
        BE-->>FE: HTTP 200 OK (Vision LLM 기반 고도화 분석 데이터)
    end
    
    FE-->>User: 분석 결과 수동 검수 & 편집 카드 UI 표시
    User->>FE: 음식 수량 수정 또는 수동 항목 추가
    User->>FE: '기록 확정' 클릭
    FE->>BE: POST /api/v3/food-log/confirm (최종 수정 데이터)
    BE->>DB: 칼로리 & 3대 영양소 최종 데이터 저장
    DB-->>BE: 저장 완료
    BE-->>FE: HTTP 200 OK
    FE-->>User: 메인 영양 대시보드 그래프 실시간 갱신
```

## 4. AI 타미 심리 공감 대화 & AI-server 종합 가공 시퀀스

사용자 메시지를 DB에 저장한 뒤 바로 AI-server로 전달하고, AI-server에서 심리 공감 응답 및 관련 웰니스/맥락 내용을 모두 종합 정리하여 BE로 전달 후 처리하는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)
    participant AI as AI-server (LLM Engine)

    User->>FE: 메시지 입력 ("오늘 마음이 싱숭생숭해")
    FE->>BE: POST /api/v3/chat/message { text }
    BE->>DB: 사용자 메시지 즉시 DB 저장
    DB-->>BE: 저장 완료
    BE->>AI: 메시지 전달 및 공감/분석 요청 { userId, messageText }
    
    Note over AI: AI-server 내부 처리
    AI->>AI: 심리 공감 응답 생성 + 감정/웰니스 관련 내용 종합 정리 및 가공
    AI-->>BE: 종합 가공 응답 { responseText, emotionSummary, motionTag }
    
    BE->>DB: AI 응답 및 가공 결과 데이터 DB 저장
    DB-->>BE: 저장 완료
    BE-->>FE: HTTP 200 OK { responseText, motionTag }
    FE-->>User: 타미 공감 대화 출력 & 캐릭터 모션 애니메이션 재생
```

## 6. 상시 웰니스 대시보드 통계 조회 시퀀스

메인 화면 진입 시 FE가 상시 웰니스 통계(칼로리 추이, 3대 영양소, 수분 섭취, 미션 달성도)를 조회하는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)

    User->>FE: 메인 웰니스 탭 진입
    FE->>BE: GET /api/v3/dashboard/summary (Date Range)
    BE->>DB: 식단 영양소, 수분 섭취량, 미션 수행 통계 데이터 집계 조회
    DB-->>BE: Raw Log & Summary Data
    BE->>BE: 칼로리 추이 선차트 및 영양 밸런스 비율 계산
    BE-->>FE: HTTP 200 OK (Dashboard Summary Data)
    FE-->>User: 웰니스 대시보드 그래프 및 미션 현황 시각화
```

## 7. JWT 로그인 & Access Token 자동 갱신 시퀀스

사용자 로그인 시 토큰 발급 및 API 요청 중 Access Token 만료 시 FE 인터셉터를 통해 Refresh Token으로 자동 재발급받는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend / Interceptor)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)

    User->>FE: 이메일/소셜 로그인 요청
    FE->>BE: POST /api/v3/auth/login
    BE->>DB: 사용자 검증 & Refresh Token 저장
    BE-->>FE: HTTP 200 OK (Access Token & Refresh Token)
    FE->>FE: Secure Storage에 토큰 저장

    Note over FE, BE: API 요청 중 Access Token 만료 발생
    FE->>BE: GET /api/v3/user/profile (Expired Access Token)
    BE-->>FE: HTTP 401 Unauthorized (Token Expired)
    
    FE->>BE: POST /api/v3/auth/refresh (Refresh Token)
    BE->>DB: DB 내 Refresh Token 검증
    DB-->>BE: 유효성 검증 성공
    BE-->>FE: HTTP 200 OK (새로운 Access Token)
    FE->>BE: GET /api/v3/user/profile (새 Access Token으로 자동 재요청)
    BE-->>FE: HTTP 200 OK (User Profile Data)
```

## 8. 회원 탈퇴 & 데이터 익명화 시퀀스

회원 탈퇴 요청 시 세션을 만료시키고 사용자 상태를 `WITHDRAWN`으로 변경하여 법적 정책에 따라 지연 삭제 및 익명화하는 과정입니다.

```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant FE as FE (App Frontend)
    participant BE as BE (Backend Server)
    participant DB as DB (Main DB)

    User->>FE: '회원 탈퇴' 선택 및 최종 확인
    FE->>BE: POST /api/v3/auth/withdraw
    BE->>DB: 사용자 상태 WITHDRAWN 변경 & Refresh Token 삭제
    BE->>DB: 개인정보 익명화 처리 (비식별화)
    DB-->>BE: 처리 완료
    BE-->>FE: HTTP 200 OK
    FE->>FE: 저장된 Local Storage / Secure Storage 세션 완전 삭제
    FE-->>User: 로그인/온보딩 화면으로 이동 ("회원 탈퇴가 완료되었습니다.")
```
