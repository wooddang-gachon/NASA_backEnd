# 📡 NASA Wellness v3 – API 명세서

> **최종 수정일**: 2026-08-10 (소스코드 기준 동기화)
> **Base URL**: `/api`
> **Swagger UI**: `/api/docs` (인증 필요: `SWAGGER_USER` / `SWAGGER_PASSWORD`)
> **인증 방식**: JWT Bearer Token (`Authorization: Bearer {token}`)
> **표준 응답 포맷**: `ApiResponse<T>` { success, data?, error?: { code, message, details? } }

---

## 📌 1. Auth – 회원 인증 및 소셜 로그인

> **Route Prefix**: `auth` | **Controller**: `AuthController`

### POST `/api/auth/signup` — 회원가입

**Request Body** (`UserSignUpRequest`):
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| email | string | ✅ | 이메일 |
| password | string | ✅ | 비밀번호 |
| nickname | string | ✅ | 닉네임 |

**Success Response** `201`: `ApiResponse<UserLoginResponse>`
| 필드 | 타입 | 설명 |
|------|------|------|
| userId | number | 사용자 ID |
| email | string | 이메일 |
| nickname | string | 닉네임 |
| accessToken | string | JWT 액세스 토큰 (1시간) |
| refreshToken | string | JWT 리프레시 토큰 (14일) |

**Error Responses**:
- `409` — `USER_ALREADY_EXISTS` (이메일 중복)

---

### POST `/api/auth/login` — 로그인

**Request Body** (`UserLoginRequest`):
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| email | string | ✅ | 이메일 |
| password | string | ✅ | 비밀번호 |

**Success Response** `200`: `ApiResponse<UserLoginResponse>`

**Error Responses**:
- `401` — `INVALID_CREDENTIALS` (이메일/비밀번호 불일치)

---

### POST `/api/auth/social-login` — 소셜 로그인

**Request Body** (`SocialLoginRequest`):
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| provider | string | ✅ | `"GOOGLE"` \| `"KAKAO"` \| `"APPLE"` |
| token | string | ✅ | 소셜 인증 토큰 |

**Success Response** `200`: `ApiResponse<UserLoginResponse>`

**Error Responses**:
- `502` — `BAD_GATEWAY` (소셜 토큰 검증 실패)

---

### POST `/api/auth/refresh` — 토큰 갱신

**Request Body** (`TokenRefreshRequest`):

|------|------|------|------|

**Success Response** `200`: `ApiResponse<TokenRefreshResponse>`

|------|------|------|
| accessToken | string | 새 액세스 토큰 |
| refreshToken | string | 새 리프레시 토큰 |

**Error Responses**:

## 📌 공통 사항

### 인증 (🔒 표시 엔드포인트)
- `Authorization: Bearer {accessToken}` 헤더 필요
- 개발 환경에서는 `mock_` 접두어 토큰 또는 쿼리 `userId` 사용 가능

### 에러 응답 형식
모든 에러는 아래 형식으로 반환:
```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "에러 설명 메시지",
    "details": {}
  }
}
```

### 공통 에러 코드
| 코드 | HTTP | 설명 |
|------|------|------|
| `VALIDATION_ERROR` | 400 | TSOA 파라미터 유효성 검증 실패 |
| `UNAUTHORIZED` | 401 | 인증 실패 / 토큰 만료 |
| `USER_NOT_FOUND` | 404 | 사용자 미존재 |
| `ROUTE_NOT_FOUND` | 404 | 요청 경로 없음 |
| `AI_SERVER_UNAVAILABLE` | 503 | AI 서버 통신 장애 |
| `INTERNAL_SERVER_ERROR` | 500 | 서버 내부 오류 |
