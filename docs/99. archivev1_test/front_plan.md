# TAMMY

Flutter / Dart / Android

TAMMY는 사진 촬영과 AI 분석을 통해 식습관을 쉽고 꾸준하게 기록할 수 있도록 돕는 웰니스 펫 에이전트 서비스입니다. 공감 능력이 뛰어난 요정 캐릭터 '타미'와의 지속적인 대화와 성장 시스템을 통해 사용자의 건강 습관을 함께 만들고 유지하도록 돕습니다.

## 1. 개요

TAMMY는 공감을 먹고 자라는 웰니스 AI 요정 캐릭터를 중심으로 한 헬스케어 앱이다. 핵심 가치는 "AI가 사용자의 자연어 발화를 분석해 건강 데이터를 자동으로 기록·분석하고, 장기기억과 생활 패턴 기반으로 먼저 말을 거는 AI 건강 에이전트"이며, 사용자의 모든 건강 행동(운동·식사·대화·감정)은 우주여행 성장 시스템을 통해 즉각적인 시각적 보상으로 연결된다. 톤은 Nintendo·Animal Crossing·Tamagotchi·Pokémon Sleep에서 영감을 받은 귀엽고 힐링되는 감성이며, 데이터 시각화는 Apple Health 수준의 절제된 스타일을 따른다.
v2까지는 기능 중심(홈 → 운동/식단/리포트 메뉴 탐색) 구조였으나, v3부터는 아래 2장의 최종 피드백에 따라 AI 채팅 중심 구조로 방향을 전환한다.

## 2. 최종 피드백 및 방향 전환 (v3 피벗)

메뉴 중심 UX → 대화 중심 UX

| 번호 | 피드백                      | 반영 방향                                                                                                                                           |
| :--- | :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 앱의 중심을 '채팅'으로 변경 | Home에서 기능을 찾아 들어가는 구조 대신, "오늘 플랭크 30분 했어" 같은 자연어 발화를 채팅에서 바로 받아 AI가 필요한 기능(기록·분석·추천)을 자동 실행 |
| 2    | AI 자동화 시스템 강화       | AI는 답변만 하는 챗봇이 아니라 입력을 분석해 기록 → 분석 → 장기기억 저장 → 리포트 반영 → 맞춤 추천까지 수행하는 AI Agent로 동작                     |
| 3    | 능동형 AI 도입              | 시간·습관·장기기억·최근 대화를 기반으로 타미가 먼저 말을 거는 구조 적용 (예: "오늘은 아직 운동 기록이 없네", "최근 스트레스를 많이 받는 것 같아")   |
| 4    | 장기기억 활용 확대          | 단순 저장에서 운동·식단 추천, 감정 분석, 월간 리포트, AI 대화 전 기능에서 참조하는 공용 컨텍스트로 확장                                             |
| 5    | 리포트 생성 방식 개선       | 고정 페이지가 아니라 AI가 운동·식단·감정·생활습관을 누적 분석해 자동 생성하거나, "이번 달 리포트 만들어줘"처럼 요청 시 즉시 생성                    |
| 6    | 채팅-기능 연결성 강화       | 운동 입력 → 운동 탭 업데이트, 식단 입력 → 식단 데이터 업데이트, 감정 입력 → 감정 리포트 업데이트처럼 채팅 발화가 전 화면에 실시간 반영              |
| 7    | 단축 입력(Shortcut) 제공    | 채팅창 주변에 운동 기록·식단 기록·물 마셨어·오늘 기분·리포트 생성 등 자주 쓰는 발화를 원탭으로 제공                                                 |
| 8    | 사이드바 개선               | 채팅 목록만 있던 사이드바를 "채팅 히스토리 + AI 기억(목표 체중·선호 운동·자주 먹는 음식 등) + 오늘 활동 요약(운동 완료·식단 기록·물 5잔)"으로 확장  |
| 9    | 행성(Planet) 시스템 개선    | 우주여행을 성장 리포트처럼 활용 — 운동별·영양별·감정별·챌린지별 등 행성마다 테마를 부여하고, 도착 시 AI가 해당 영역의 성장 내용을 요약              |
| 10   | 홈 화면 단순화              | Home = 타미 + 채팅 진입 + 추천 질문 + 오늘 요약 수준으로 단순화하고, 나머지 기능은 모두 채팅으로 연결                                               |
| 11   | AI 응답 방식 개선           | 챗봇 톤이 아니라 "오늘도 운동했네! 정말 꾸준하다 😊"처럼 친구가 말하듯 짧고 자연스러운 말풍선 톤 유지                                               |
| 12   | UX 방향 재정의              | 사용자가 기능을 찾는 UX → AI가 필요한 기능을 먼저 실행하는 UX로 전환                                                                                |

## 4. 내비게이션 구조 (v3)

하단 5-tab 고정 내비게이션(홈 · 채팅 · 활동 · 여행 · 마이) 골격은 유지하되, 채팅을 앱의 실질적 중심으로 둔다. Home은 채팅 탭이되고, 활동/여행 탭은 채팅에서 자동 반영된 데이터를 "확인"하는 뷰로 역할이 바뀐다. 390–430px 모바일 우선 프레임, safe-area 대응.

## 5. 구현된 화면

### 5.1 Home — 단순화

카드가 많던 v2 구조를 걷어내고 아래 4가지로 압축한다. 운동/식단/리포트 등 나머지 기능은 카드 진입이 아니라 채팅 발화로 연결된다.

- 대형 TAMMY 캐릭터 + 플로팅 애니메이션, 인사말·말풍선
- 추천 질문(오늘 기분 어때? / 운동 추천해줘 / 이번 주 리포트 보여줘)
- 실시간 우주 진행 스트립(연료 게이지 위 우주선 이동) — 채팅에서 발생한 행동이 즉시 반영

### 5.2 Chat — 앱의 중심

단순 Q&A 챗봇이 아니라, 발화를 분석해 기록·분석·추천을 자동 실행하는 AI Agent 인터페이스로 재정의한다.

- **자연어 → 자동 실행**: "플랭크 30분 했어", "물 한 잔 마셨어", "오늘 좀 힘들었어" 같은 발화를 의도 분류 후 해당 데이터(운동/수분/감정)로 자동 기록하고, 그 결과가 활동·여행·리포트 화면에 즉시 반영됨을 말풍선으로 확인시켜준다("운동 탭에 기록했어! 우주선도 조금 움직였어 🚀")
- **능동형 개시**: 타미가 먼저 말을 거는 케이스 지원 — 평소 시간대에 운동/수분 기록이 없거나 부정적 감정이 반복되면 세션 진입 시 선제적으로 안부·제안 메시지 표시
- **단축 입력(Shortcut)**: 입력창 위에 운동 기록 · 식단 기록 · 물 마셨어 · 오늘 기분 · 리포트 생성 원탭 칩 상시 노출(빈도 높은 발화 우선 배치)
- **사이드바**: 채팅 히스토리 목록 + "AI 기억"(목표 체중·선호 운동·자주 먹는 음식 등 장기기억 요약) + "오늘 활동 요약"(운동 완료 여부·식단 기록 수·물 N잔)을 한 화면에서 조회. 기억 항목을 탭하면 원본 대화로 이동
- LINE 스타일 말풍선, 타미 아바타는 연속 메시지 그룹의 첫 말풍선에만 노출
- **STT**: 입력창 옆 원형 마이크. Web Speech API(SpeechRecognition, ko-KR) 실시간 텍스트화 → 입력창 자동 반영. 듣는 중 Pulse 링 + 음성 파형 바 애니메이션 + "듣는 중…" 상태. 미지원 브라우저/마이크 권한 거부/무음 인식 실패 각각 안내 메시지 처리
- **TTS**: 타미 메시지마다 🔊 버튼. SpeechSynthesis(ko-KR)로 즉시 낭독, 읽는 중 아이콘 펄스, 재클릭 시 중지, AI 응답은 자동 낭독. 미지원 브라우저 안내 처리
- **공감 전용 페르소나**: 명령·판단·훈계 금지, 공감·응원·위로 중심의 짧고 자연스러운 반말 응답("오늘도 운동했네! 정말 꾸준하다 😊" 같이 친구 톤 유지)
- **장기기억**: 대화가 기기에 영속 저장되고, 대화 중 파악한 사용자 정보를 기억 목록으로 누적해 운동·식단 추천, 감정 분석, 월간 리포트, 이후 대화 전반에서 참조하는 공용 컨텍스트로 사용 → 채팅 상단 "기억 N개" 배지로 노출

### 5.3 Food Analysis (음식 분석)

사진 분석은 여전히 전용 화면을 갖지만, v3에서는 채팅에서 "밥 먹었어" + 사진 첨부로도 동일 플로우가 트리거되고 결과가 채팅 말풍선으로도 요약된다.

- 사진 촬영 / 갤러리 선택 진입
- 분석 중 스피너 오버레이 애니메이션 ("AI 분석 중…")
- 결과: 음식명 · 칼로리 · 탄수화물/단백질/지방 각각 프로그레스 바 카드
- 분석 결과에 따른 타미 코멘트(만족/배부름 등 감정 반응)
- "오늘 식단에 기록" 시 오늘 섭취 칼로리 누적 + 우주 연료 +5 즉시 지급

### 5.4 AI 운동 추천 (Exercise)

4단계 플로우로 구성:

| 단계          | 내용                                                                                                                                                                                             |
| :------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 프로필 입력 | 성별·나이·키·몸무게·운동 목표(4)·경험(3)·장소(2)·시간(4) — 칩 선택형, localStorage 저장, 언제든 수정 가능                                                                                        |
| ② 추천 결과   | 제목·이모지·예상 시간/칼로리·난이도(★) 카드 + 운동 리스트(이미지·이름·세트·횟수·칼로리)                                                                                                          |
| ③ 운동 상세   | 탭하면 운동 방법 단계별 안내, 운동 부위, 주의사항, "운동 시작" 버튼                                                                                                                              |
| ④ 진행/완료   | 세트별 카운트다운 타이머, 진행률 바, 일시정지/중단, 세트 완료 시 "다음 운동으로" 버튼. 전체 완료 시 축하 애니메이션 + 운동 시간·소모 칼로리·완료 개수 요약 + 연속 기록 배지 안내 + 우주 연료 +10 |

타미는 시작 시 "좋아요, 함께 운동해요!", 진행 중 "조금만 더 힘내요!", 완료 시 "오늘 목표를 달성했어요!"로 반응한다.

### 5.5 Growth (성장)

대형 캐릭터, Lv./EXP 바, 공감도·건강 지수·활동 지수·행복 지수 4종 프로그레스, 타미별까지의 여정 타임라인(도착/현재/예정 상태 구분).

### 5.6 Space Travel (우주여행) — 성장 리포트로 확장

정적 리포트가 아닌 행동 연동 실시간 성장 시스템으로 설계했다. v3에서는 행성 각각에 영역 테마를 부여해, 단순 진행률 게이지를 넘어 "행성 = 해당 영역의 성장 리포트"로 의미를 확장한다.

- **연료 시스템**: 음식 분석 완료 +5, 운동 완료 +10, 오늘 목표(전 미션) 달성 +15. 채팅에서 자연어로 기록되어도 동일하게 연료가 지급된다. 이벤트 발생 즉시 게이지가 스프링 애니메이션으로 증가하고 보상 토스트("+N 연료 · 타미 리액션 문구")가 표시된다
- **우주선 이동**: 홈 상단 스트립과 여행 화면 모두에서 우주선 아이콘이 연료 비율에 따라 실제 좌표로 이동(트랙 위 절대 위치, easing 트랜지션)
- **테마 행성 지도**: 지구 → 💪 운동별 → 🍽 영양별 → 😊 감정별 → 🏆 챌린지별 순으로 연결하고, 현재 위치는 우주선 아이콘 + 글로우로 표시
- **행성 도착 연출 + AI 요약**: 연료 100% 도달 시 전체 화면 오버레이(행성 확대 spring, Confetti, 타미 축하 문구)에 더해 해당 행성 영역의 이번 구간 성장 내용을 AI가 한 문단으로 요약(예: 운동별 도착 시 "이번 주 운동 4회, 평균 강도가 올라갔어!"). "계속 여행하기" CTA로 다음 행성 이동
- 상태는 localStorage에 영속화되어 앱 재실행 후에도 유지

### 5.7 Monthly AI Health Report (월간 리포트) — 온디맨드 생성

"음식 + 운동 + AI 분석"에 집중하고 물·수면 등 부가 지표는 배제해 에이전트 컨셉의 초점을 유지했다. v3에서는 고정 화면으로만 존재하지 않고, 채팅에서 "이번 달 리포트 만들어줘"처럼 요청하면 누적된 장기기억·활동 데이터를 즉시 집계해 같은 리포트를 생성해 준다(정기 자동 생성 + 온디맨드 생성 병행).

- 상단 요약: 이번 달 건강 점수, 목표 달성률
- 음식 분석: 일별 칼로리 라인 차트, 탄/단/지 도넛 차트, 가장 많이 섭취한 음식 Top3
- 운동 분석: 주간 운동량 바 차트, 총 운동시간·소모 칼로리, 근력/유산소 비율 바
- AI 분석(타미 코멘트): 각 섹션 및 종합 카드에 "데이터 → 해석 → 다음 달 행동 제안" 형태의 문장형 인사이트 삽입 (예: "탄수화물 섭취가 다소 높아 오후 피로감을 느낄 가능성이 있어요")
- 다음 달 AI 추천 체크리스트(4항목)
- 우주여행은 하단에 보조 요약으로만("이번 달 습관으로 우주선이 78% 이동했어요") 축소 배치 — 메인 콘텐츠는 어디까지나 음식/운동/AI 분석

### 5.8 My Page

프로필(닉네임·함께한 일수), 레벨/연속기록/방문 행성 요약, 달성 배지, 알림/방해금지 토글, 테마 선택, 타미의 응원 카드.

## 6. AI 기능 구현 리스트 (자동화 · 능동형)

타미의 장기기억은 단순 저장이 아니라 자동화(수동 발화 인식 → 자동 기록/분석)와 능동형(타미가 먼저 묻고 제안) 두 층위로 동작한다. 2장에서 정리한 채팅 중심 구조의 실행 규칙이 바로 이 표이며, 채팅 한 곳에서 발화하면 감정 리포트·활동 기록·건강 리포트 전반에 반영된다.

| 범주     | 내용                | 기능 구현 방식                                                                                                                                                                                                                                                                                                              |
| :------- | :------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 공통     | 감정                | 자동화: 채팅에서 감정(기쁨·슬픔·스트레스 등)과 원인을 AI가 자동 분석해 장기기억에 저장하고 감정 리포트에 반영한다.<br>능동형: 최근 부정적인 감정이 반복되면 타미가 먼저 안부를 묻거나 원인을 질문해 감정 변화를 지속적으로 관리한다.                                                                                        |
| 공통     | 일상대화            | 자동화: 대화에서 목표·취미·음식 취향·생활 패턴 등 반복되는 정보를 AI가 중요도 기반으로 장기기억에 저장한다.<br>능동형: 자주 언급되는 내용은 "앞으로 기억해둘까?"처럼 사용자 확인 후 장기기억으로 등록한다.                                                                                                                  |
| 생활습관 | 물 마시는 주기      | 자동화: "물 한 잔 마셨어" 같은 자연어를 인식해 수분 섭취량·시간을 자동 기록하고 일일 목표를 계산한다.<br>능동형: 평소 섭취 패턴을 학습해 일정 시간 기록이 없으면 자연스럽게 물 섭취를 제안한다.                                                                                                                             |
| 생활습관 | 스트레칭            | 자동화: "스트레칭 했어" 같은 입력을 기록하고 활동량에 반영한다.<br>능동형: 장시간 활동이나 공부·업무 관련 대화가 지속되면 AI가 피로도를 추정해 스트레칭을 권장한다.                                                                                                                                                         |
| 생활습관 | 운동                | 자동화: "플랭크 30분 했어", "5km 뛰었어" 같은 자연어를 분석해 운동 종류·시간·강도를 분류하고 예상 칼로리를 계산해 기록한다. 이후 장기기억과 운동 이력을 기반으로 다음 운동이나 보완 운동을 추천한다.<br>능동형: 평소 운동 시간인데 기록이 없거나 운동량이 감소하면 AI가 먼저 운동 계획을 물어보거나 가벼운 운동을 제안한다. |
| 생활습관 | 일기 / 상담         | 자동화: 하루 동안의 대화와 감정을 AI가 요약해 자동 일기를 생성하고 주요 사건과 감정 변화를 기록한다.<br>능동형: 하루 마무리 시간에 "오늘 가장 기억에 남는 일이 뭐야?"처럼 질문해 일기를 보완하고 상담형 대화를 이어간다.                                                                                                    |
| 생활습관 | 수면 시간           | 자동화: 사용자 입력과 마지막·첫 대화 시간을 종합해 수면 패턴을 추정하고 장기기억에 반영한다.<br>능동형: 늦은 취침이나 수면 부족 패턴이 반복되면 다음 날 컨디션을 고려한 운동 및 생활 습관을 추천한다.                                                                                                                       |
| 생활습관 | 약 복용 (선택 기능) | 자동화: 사용자가 등록한 약의 이름과 복용 주기를 기억하고, "약 먹었어" 같은 입력 시 복용 시간을 자동 기록한다.<br>능동형: 복용 시간이 되었는데 기록이 없으면 "평소 이 시간에 약을 복용했는데 오늘도 복용했어?"처럼 대화형으로 확인한다.                                                                                      |

## 7. 기술 아키텍처

### 7.1 스택

React 18 · TypeScript · Tailwind CSS(디자인 토큰화) · Framer Motion(스프링/플로팅/페이드/스케일/진행률 애니메이션) · Vite

### 7.2 폴더 구조

```
frontend/src/
├── api/client.ts          # USE_MOCK 플래그로 mock ↔ 실서버 전환
├── mocks/                 # food · exercise · report · chat · planets mock data
├── types.ts               # 도메인 타입 (API 응답과 1:1 매핑)
├── hooks/
│   ├── useFuel.tsx        # 우주여행 성장 시스템 단일 소스
│   ├── useChat.ts         # 대화 + 장기기억(localStorage)
│   └── useSpeech.ts       # STT/TTS 래퍼
└── components/
    ├── ui/                # Card, PrimaryButton, ProgressBar 등 공통 UI
    ├── space/             # SpaceStrip, RewardToast, ArrivalOverlay
    ├── layout/BottomNav
    └── screens/           # Home / Chat / Food / Exercise / Report / Travel
```

### 7.3 데이터 모델 (Mock → API 매핑)

v3에서는 POST `/chat`의 응답이 reply 텍스트뿐 아니라 actions(예: `{ type: 'LOG_WORKOUT', payload }`) 배열을 함께 반환해, 채팅 한 번의 발화가 아래 표의 다른 엔드포인트 데이터를 갈아치우는 구조로 확장될 예정이다.

| Method | Path        | 응답 타입                                                                             | 화면         |
| :----- | :---------- | :------------------------------------------------------------------------------------ | :----------- |
| POST   | `/food`     | NutritionData (food, calories, carbohydrate, protein, fat, comment)                   | 음식 분석    |
| GET    | `/exercise` | ExercisePlan (title, exercises[], totalMinutes, totalCalories, difficulty)            | AI 운동 추천 |
| GET    | `/report`   | MonthlyReport (healthScore, dailyKcal[], macros[], weeklyWorkoutMin[], aiFindings[]…) | 월간 리포트  |
| POST   | `/chat`     | `{ reply, memory }`                                                                   | 채팅         |

모든 화면 컴포넌트는 데이터를 직접 하드코딩하지 않고 props/훅을 통해 주입받으므로, 위 4개 엔드포인트만 연결하면 백엔드 데이터로 자동 전환된다.

### 7.4 우주여행 이벤트 API

```javascript
const { addFuel } = useFuel();
addFuel("FOOD_ANALYZED"); // +5 연료
addFuel("WORKOUT_DONE"); // +10 연료
addFuel("GOAL_ACHIEVED"); // +15 연료
```

이 한 줄 호출만으로 게이지 갱신, 토스트, 행성 도착 판정/연출, localStorage 저장이 전부 자동 처리된다. 보상 정책은 `mocks/planets.ts`의 `FUEL_REWARDS`에서 중앙 관리한다.
